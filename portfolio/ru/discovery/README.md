# Каталог сценариев

В каталоге сценариев собраны сценарии применения AI в Банке по направлениям услуг и областям: по каждому — проблема, предлагаемое решение и опережающие индикаторы. Каталог пополняет воронку: сценарий становится инициативой, только когда подразделение заявляет соответствующую потребность и руководитель AICC вносит её в [бэклог портфеля](../portfolio-backlog.md) в состоянии «Предложено» (п. 5.2 Модели управления портфелем). Сценарий не является инициативой и не имеет состояния канбана портфеля.

Каталог ведётся в виде сформированных страниц на обоих языках в `html-alt/financial-services/{en,ru}/` и публикуется как раздел «Каталог сценариев для применения AI» портала AICC. Он будет перенесён в эту папку, когда его исходные записи будут отделены от генератора; до этого папка фиксирует его расположение и правило.

Когда сценарий вносится в воронку, в паспорте инициативы указывается сценарий, из которого она возникла, чтобы связь каталога с бэклогом портфеля сохранялась.
