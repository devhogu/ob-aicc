# Пакеты

Каталог пакетов, которые остаются по итогам взаимодействий AICC с заказчиками или предусмотрены для них. По каждому пакету в `packages/` есть описание пакета, на которое дана ссылка. Для имеющихся материалов указаны конкретные ссылки на источники и порядок повторного развёртывания; для запланированных и готовящихся пакетов указано, чего ещё не хватает. Статус пакета — «запланирован», «в подготовке», «доступен» или «отозван»; статус пакета не является состоянием элемента.
