# Портфель

В портфеле перечислены и описаны решения, которые AICC создаёт для подразделений Банка или контролирует, а также пакеты, остающиеся по итогам взаимодействий с заказчиками: что AICC может сделать, что он решил сделать и как описано каждое решение. Портфель содержит описания, объём, методы и архитектуру. Он не содержит числовых показателей Банка, данных, документов подразделений и кода. Работа в ходе выполнения и управленческие решения по ней находятся в реестре (`registry/`), а правила — в корпусе документов (`charter/`).

| Папка | Содержание |
| --- | --- |
| [solutions/](solutions/SOL-001-fpa-board-reporting-pipeline.md) | По одному описанию решения на каждое решение, составленному по шаблону «Описание решения», с указанием типа (сервис, продукт или эксперимент), получателя и состояния |
| [packages.md](packages.md) | Каталог пакетов: по каждому пакету — идентификатор, вид, категория услуг, статус, ответственный, пользователи, условия повторного развёртывания в подразделении и место хранения |
| [packages/](packages.md) | Двенадцать описаний пакетов, на каждое из которых есть ссылка из каталога; для имеющихся материалов указаны ссылки на источники, для запланированных и готовящихся — явно обозначенные пробелы |
| adopted-solutions/ | По одной записи на каждое внедрённое решение — решение, которое создают другие участники, а AICC контролирует. Папка создаётся вместе с первой записью |

Каталог отражает состояния и стадии, установленные разделом 5 Модели жизненного цикла решений и разделом 5 Модели управления портфелем. Описание решения составляет инженер решений на стадии «MVP» инициативы; в актуальном состоянии его поддерживают инженер решений и руководитель AICC. Описание пакета открывается, когда категория услуг предусматривает пакет или пакет остаётся по итогам взаимодействия с заказчиком; в актуальном состоянии его поддерживают ответственный за пакет и руководитель AICC.
