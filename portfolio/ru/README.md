# Портфель

Портфель перечисляет и описывает Решения, которые AICC поставляет функциям Банка или над которыми осуществляет надзор, а также Пакеты, остающиеся по итогам Взаимодействий с заказчиками: что AICC может делать, что решил делать и как определено каждое Решение. Он содержит описания, границы, методы и архитектуру. Он не содержит числовых данных Банка, данных, документов функций или кода. Текущая работа и решения по ней находятся в Реестре (`registry/`), а правила — в корпусе документов (`charter/`).

| Папка | Содержание |
| --- | --- |
| [solutions/](solutions/SOL-001-fpa-board-reporting-pipeline.md) | Одно Описание решения для каждого Решения по соответствующему Шаблону, с типом (Сервис, Продукт или Эксперимент), Получателем и состоянием |
| [packages.md](packages.md) | Каталог Пакетов: идентификатор, вид, Категория услуг, статус, владелец, пользователи, условия повторного развёртывания в функции и место хранения каждого |
| [packages/](packages.md) | Двенадцать Описаний пакетов, связанных с Каталогом, со ссылками на источники доступных материалов и явным указанием недостающего для запланированных или подготавливаемых материалов |
| adopted-solutions/ | По одной записи для каждого Внедрённого решения: Решения, которое поставляют другие и над которым AICC осуществляет надзор. Папка создаётся с первой записью |

Каталог следует состояниям и Стадиям Модели жизненного цикла решений 5 и Модели управления портфелем 5. Описание решения создаёт Инженер решений на этапе MVP Инициативы; актуальность поддерживают Инженер решений и Руководитель AICC. Описание пакета создаётся, когда Категория услуг предусматривает Пакет или он остаётся по итогам Взаимодействия с заказчиком; актуальность поддерживают Владелец пакета и Руководитель AICC.
