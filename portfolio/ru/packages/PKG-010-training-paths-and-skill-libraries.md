## 1. Содержание и решаемая задача

Обучение по ролям, библиотеки запросов и навыков по направлениям работы, формат практических консультаций, практические инструкции.

## 2. Состав

Каталог описывает предполагаемый состав следующим образом: Обучение по ролям, библиотеки запросов и навыков по направлениям работы, формат практических консультаций, практические инструкции. Отдельный пакет этих компонентов с учётом версий в текущем Каталоге не указан. Настоящее Описание фиксирует предполагаемый объём и не утверждает, что компоненты завершены.

## 3. Порядок повторного развёртывания в функции

1. Принимающая функция предоставляет: роли и направление работы функции, Эксперт Домена.
2. Владелец определяет ресурсы реализации, их версию, Зависимости и инструкции по использованию.
3. Владелец проверяет пакет на примерах принимающей функции и фиксирует результат и применимые одобрения использования ИИ.
4. Статус в Каталоге меняется на «Доступен» только при фактической доступности материалов и инструкций повторного развёртывания. До этого объём работ определяется через обычный приём запросов.

## 4. Ограничения и риски

Текущий статус не позволяет принять обязательство по немедленному повторному развёртыванию. Принимающая функция отвечает за источники данных и бизнес-приёмку. Каждое применение ИИ требует собственного Описания решения, Категории риска, одобрения использования данных и Проверки либо Валидации; настоящее Описание пакета не является таким одобрением.
