# Команды

Команды, которые выполняют работу. В команду входят инженер решений, эксперт направления, владелец направления и владелец продукта. Пока в команде не более трёх человек, её владельцем продукта является руководитель Центра Компетенций (п. 7.3 Модели жизненного цикла решений). Представитель заказчика по приёмке — владелец направления, а по обеспечивающим работам — куратор Центра Компетенций; он принимает решения, созданные командой. Одно лицо вправе входить в несколько команд.

| Команда | Участники | Представитель заказчика по приёмке | Направление |
| --- | --- | --- | --- |
| Команда Центра Компетенций |  | Куратор Центра Компетенций — по обеспечивающим работам | Центр Компетенций |
| Команда FP&A |  | Руководитель подразделения FP&A | FP&A |
| Комплаенс, персонал, правовые вопросы, финансы, бухгалтерский учёт |  | Руководитель каждого подразделения | Подразделения |
| Коммерческий фронт-офис, розничный бизнес, коммерческие продажи |  | Руководители подразделений | Фронт-офис |
| Розничное кредитование |  | Руководитель подразделения розничного кредитования | Розничное кредитование |
| Базы знаний подразделений (INI-008) |  | Руководитель каждого подразделения — в своей части; куратор Центра Компетенций — в целом | Подразделения |

Участники команд пока не указаны.

Команда Центра Компетенций работает над INI-002; это обеспечивающие работы, по которым представителем заказчика по приёмке является куратор Центра Компетенций.
