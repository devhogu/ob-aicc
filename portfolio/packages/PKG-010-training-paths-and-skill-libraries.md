## 1. What it is and what problem it answers

Training by role, prompt and skill libraries per line of work, clinic format, playbooks.

## 2. What it contains

The catalog describes the intended content as: Training by role, prompt and skill libraries per line of work, clinic format, playbooks. A separately versioned package of these components is not identified in the current catalog. This Definition records the intended scope; it does not claim that those components are complete.

## 3. How a function re-deploys it

1. The receiving function supplies: the roles and the line of work of the function, and a Domain Expert.
2. The Owner identifies the implementation assets, their version, their dependencies, and the instructions for their use.
3. The Owner checks the package against the receiving function's cases and records the result and the applicable AI approvals.
4. The catalog status becomes Available only when the material and the instructions for re-deployment are actually available. Until then the work is scoped through the normal intake.

## 4. Limits and risks

The current status does not support a commitment to immediate re-deployment. The receiving function owns the data sources and business acceptance. Each AI use requires its own Solution Definition, Risk Tier, data-use approval, and check or validation; this Package Definition is not that approval.
