## 1. Hypothesis

If AICC identifies and presents the current service architecture landscape, from commercial portfolio management down to IT architecture and infrastructure, then it can see where AI adoption can start with least disturbance and where adoption has already started.

## 2. Problem or opportunity, and minimum scope

Going around the functions and services to collect service knowledge, and building a portal that projects the current service architecture. The work is done in the EA repository under the obank folder. It shows where AI is already in use.

## 3. Benefit, cost, and risk

| Benefit | Measure | Baseline | Target | Date |
| --- | --- | --- | --- | --- |
| The landscape portal presented; a list of where AI adoption can start and where it has started | to be set with the Domain Owner | to be set | to be set | end of quarter 0 |

Cost: the time of the AICC Lead, with no other cost stated. Enabling work: produces knowledge, builds no AI Solution.

## 4. Decision

Approved as a goal of the first 100 days (September to December 2026) by the Executive Sponsor. Decision Log entry DR-2026-012.
