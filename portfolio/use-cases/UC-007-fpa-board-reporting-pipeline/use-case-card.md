## 1. The work

An agentic pipeline that collects the financial metrics from their sources, calculates them, drafts the monthly and quarterly editions, and publishes them to the Board portal. FP&A produces these reports today with AI and some manual steps.

## 2. Benefit and success Measures

| Consistent reporting with fewer manual steps | Editions issued on time; manual steps; hours per cycle | to be set by 31 October 2026 | to be set | | |

## 3. Data, users, and effect on persons

Financial data, not personal data, from governed sources with an owner and a review date. The pipeline reads the sources and has no right to change them. Publishing is a human act after the approval of the Executive Sponsor. The output reaches the Board and may reach investors: the Control Function Contact of compliance confirms the disclosure rules before the first issue. The AI influences the content of a report and no decision on a person.

## 4. Risk Tier

Risk Tier 2 is expected. The AICC Lead assigns it and tells the Domain Owner; a Control Function Contact may raise it. Risk Tier 3 would apply only if the pipeline acted on systems or funds, which it does not.

## 5. Scores

Value 5, urgency 5, risk reduction or opportunity 4, effort 3.
