# O! UI/UX kit 0.1.1

Internal O! portal implementation kit. Serve this directory as static files and open index.html. Start with ADOPT.md for reuse. Editable source: obank-uiux/design-system/ in the AICC repository; base tokens: obank-uiux/tokens/; curated assets: obank-uiux/ui-comps/.

Guide explanations are English; shell and interactive examples support Russian and English. Example records are fictional and browser-only. Fonts retain the internal-use restriction in assets/FONT-USE.md.
