Functional page patterns

Each example uses the same shell, tokens, assets and components. The fictional service wording demonstrates layout and behaviour only. Try the theme and language controls, the narrow navigation disclosure and each pattern's main interaction.

Pattern anatomy

Pattern Reader task Main interaction Central/supporting composition
Overview Understand a portfolio/workspace and select an area Open an area from its summary Summary and area cards; concise scope context
Catalogue Find and inspect a subject Search, filter, clear and open a profile Results in the centre; tools above
Profile Understand one selected subject Switch accessible tabs; follow contents Main explanation centrally; outline on the right
Flow Follow a recorded sequence or handoff Select a stage and read its explanation Diagram and detail centrally; text sequence available
Comparison Examine differences between arrangements Switch the comparison group Aligned facts; labelled scroll region
Form Enter or change a small record Validate, review in a dialog, return to edit Form centrally; brief supporting guidance
Activity Understand dated changes Filter change type Dated groups, subject links and qualifications

The examples intentionally show fewer controls than a full product. Reuse the pattern and supply the real application's content, loading/error states, permissions and persistence through its own implementation.

For a dense stage-by-concern map that keeps sequence visible, use the Cloud LAB flow-first pattern. It records the accepted AICC page's layout and interaction choices; the six stages and five concerns are example content, not a universal grid.
