# Decisions

A Decision Record for each hard-to-reverse Decision of the Executive Sponsor and each Decision that the Operating Model 8 names as evidenced by one. The Decision Log indexes them. The folder holds the Decision Records from DR-2026-060, from the Decision Record Template.

A Decision Record is named with its identifier and a short title, for example `DR-2026-060-baseline-of-the-charter-and-the-registry.md`. The identifier is DR-yyyy-nnn.
