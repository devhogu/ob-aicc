# Инициативы

Для каждой Инициативы создаётся папка с идентификатором INI-nnn и кратким названием, например `INI-002-service-landscape-discovery/`. Она содержит Паспорт инициативы (`brief.md`), Соглашения о взаимодействии и Отчёты о результатах соответствующего Взаимодействия с заказчиком, а также Функциональные возможности и Функциональности.
