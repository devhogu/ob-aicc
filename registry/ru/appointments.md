# Назначения

Настоящий документ — реестр назначений, оформленный по шаблону «Реестр назначений». В нём роли корпуса документов сопоставляются с конкретными работниками. Это реестр, в котором указываются исполнители ролей; в нём хранятся их имена и должности, декларации, согласия и сведения о доступе, иные персональные данные в нём не хранятся. В часть C записи только добавляются. Одно лицо вправе исполнять несколько ролей; каждая роль указывается отдельной строкой. Имена хранятся здесь, а не в корпусе документов.

## Часть B. Распределение ответственности

Матрица RACI корпуса документов приведена в Руководстве по организации. Совмещения ролей, которые запрещены правилами разделения обязанностей, являются принятыми ограничениями; каждое из них внесено в реестр рисков и проблем с указанием компенсирующей контрольной процедуры.

Принятых ограничений пока не зарегистрировано.
