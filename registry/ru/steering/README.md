# Управляющие совещания

Итоги Управляющих совещаний составляются по соответствующему Шаблону и именуются по дате и типу, например `2027-01-29-monthly.md` или `2027-03-26-quarterly.md`. Фиксируются только рассмотренные вопросы, рекомендации, Управленческие решения и действия. В месяце с Неделей инноваций и планирования отдельное ежемесячное Управляющее совещание не проводится: совещанием этого месяца является ежеквартальное Управляющее совещание (Операционная модель 6.7). Исключение — декабрь: ежемесячное совещание проводится в первые две недели как Ежегодное Управляющее совещание, и в имени файла его итогов указывается тип `yearly`.
