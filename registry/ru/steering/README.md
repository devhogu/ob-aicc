# Управляющие совещания

Итоги управляющих совещаний оформляются по шаблону «Итоги управляющего совещания»; имя файла состоит из даты и вида совещания, например `2027-01-29-monthly.md` или `2027-03-26-quarterly.md`. В итогах фиксируются только рассмотренные вопросы, рекомендации, управленческие решения и поручения. В месяце, на который приходится неделя IP, отдельное ежемесячное управляющее совещание не проводится, и управляющим совещанием этого месяца является ежеквартальное управляющее совещание (п. 6.7 Операционной модели). Исключение составляет декабрь: ежемесячное управляющее совещание проводится в первые две недели месяца как ежегодное управляющее совещание, и в имени файла его итогов указывается вид `yearly`.

Итогов управляющих совещаний пока не зарегистрировано.
