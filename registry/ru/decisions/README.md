# Управленческие решения

Запись о решении составляется для каждого труднообратимого Управленческого решения Куратора AICC и каждого решения, для которого Операционная модель 8 требует такого подтверждения. Их перечень ведётся в Журнале решений. Папка содержит Записи о решениях начиная с DR-2026-060, составленные по Шаблону Записи о решении.

Имя файла включает идентификатор и краткое название, например `DR-2026-060-baseline-of-the-charter-and-the-registry.md`. Формат идентификатора — DR-yyyy-nnn.
