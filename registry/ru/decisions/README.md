# Записи о решениях

Запись о решении составляется по каждому труднообратимому управленческому решению куратора AICC и по каждому управленческому решению, подтверждающей записью которого согласно разделу 8 Операционной модели служит запись о решении. Записи о решениях индексируются в журнале решений. В папке хранятся записи о решениях начиная с DR-2026-060, составленные по шаблону «Запись о решении».

Имя файла записи о решении состоит из её идентификатора и краткого наименования, например `DR-2026-060-baseline-of-the-charter-and-the-registry.md`. Идентификатор имеет вид DR-yyyy-nnn.
