# Протоколы решений

Протокол решения составляется по каждому труднообратимому управленческому решению куратора AICC и по каждому управленческому решению, подтверждающим документом которого согласно разделу 8 Операционной модели служит протокол решения. Протоколы решений индексируются в журнале решений. В папке хранятся протоколы решений начиная с DR-2026-060, составленные по шаблону «Протокол решения».

Имя файла протокола решения состоит из его идентификатора и краткого наименования, например `DR-2026-060-baseline-of-the-charter-and-the-registry.md`. Идентификатор имеет вид DR-yyyy-nnn.
