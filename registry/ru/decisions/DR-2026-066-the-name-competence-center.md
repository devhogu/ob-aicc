# DR-2026-066 Наименование «Центр компетенций»

| Поле | Содержание |
| --- | --- |
| Идентификатор | DR-2026-066 |
| Наименование | В тексте для читателя подразделение называется «Центр компетенций», в заголовках — «Центр компетенций по AI»; AICC сохраняется только как код |
| Дата | 2026-10-07 |
| Вид | Наименования в корпусе документов |
| Уровень | Корпус документов, рабочие документы и портал; операционные решения остаются за прежними ответственными |

| Статус | Принято |

## 1. Факты

Сокращение AICC использовалось как наименование подразделения в тексте корпуса документов, рабочих документов и портала, а один из разделов портала назывался «Center». Читатель встречал три наименования одного и того же.

## 2. Управленческое решение

1. В тексте для читателя подразделение называется «Центр компетенций» (англ. Competence Center); в заголовке и в наименовании документа — «Центр компетенций по AI» (AI Competence Center).
2. Роль AICC Lead называется «руководитель Центра компетенций» (Competence Center Lead).
3. AICC сохраняется только как код: пути и адреса, идентификаторы документов, например AICC-TPL-02, имена файлов и другие идентификаторы.
4. Закрытые подтверждающие документы не переписываются (п. 7.4 Операционной модели); документы, оформляемые с сегодняшнего дня, используют новое наименование.

## 3. Полномочия и ограничения

Протокол фиксирует указание руководителя Центра компетенций как ответственного за документы и рабочие документы. Изменяются только наименования: роли, обязанности, права, решения, состояния и обязательства не изменяются.
