# Команды

Команды, выполняющие поставку. Команда включает Инженера решений, Эксперта Домена, Владельца Домена и Владельца продукта. Пока в Команде не более трёх человек, её Владельцем продукта является Руководитель AICC (Модель жизненного цикла решений 7.3). Представитель заказчика по приёмке — Владелец Домена, а для Обеспечивающих работ — Куратор AICC; он принимает Решения Команды. Одно лицо может участвовать в нескольких Командах.

| Команда | Участники | Представитель заказчика по приёмке | Домен |
| --- | --- | --- | --- |
| Команда AICC | Timur Alimbayev (Руководитель AICC и Инженер решений) | Куратор AICC, для Обеспечивающих работ | AICC |
| Команда FP&A | Timur Alimbayev (Инженер решений) | Ademi Moldogazieva | FP&A |
| Комплаенс, HR, юридическая, финансовая и бухгалтерская функции | Timur Alimbayev (Инженер решений) | Руководитель каждой функции | Функции |
| Коммерческий фронт-офис, розничное направление, коммерческие продажи | Timur Alimbayev (Инженер решений) | Руководители функций | Фронт-офис |
| Розничное кредитование | Timur Alimbayev (Инженер решений) | Руководитель функции розничного кредитования | Розничное кредитование |
| Базы знаний в функциях (INI-008) | Timur Alimbayev (Инженер решений) | Руководитель каждой функции в своей части; Куратор AICC в целом | Функции |

Команда AICC обслуживает INI-002 — Обеспечивающие работы, для которых Представителем заказчика по приёмке является Куратор AICC.
