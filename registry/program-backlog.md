# Program Backlog

The Program Backlog, also called the PI Backlog: the ranked Capabilities (capabilities) and Features. A Capability may run over several Program Increments. A Feature closes within its Program Increment, or is split. It flows through the Program Kanban (board.md). A Feature is approved only when its Dependencies are known. Initiatives INI-002, INI-003, INI-004, INI-006, INI-007, and INI-008 are in discovery, so they have no Capabilities yet. Their Capabilities come from the Solution Definitions.
