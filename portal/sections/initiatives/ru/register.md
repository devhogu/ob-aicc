# Реестр инициатив

Пока для этого реестра не отобрано ни одной инициативы.

По мере отбора в реестре появятся описания бизнес-проблемы, ожидаемого результата, владельца, границ работ, принятого решения и текущего статуса. Сам по себе отбор не означает одобрения реализации или подтверждения полученного эффекта.
