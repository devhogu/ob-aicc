# OWASP Top 10 for Large Language Model Applications

The security community's list of the ten most important risks of applications built on large language models, maintained by the project that gave the web its best-known security list. It is the reference for the security test of an AI Solution.

## 1. Identity

| Item | Entry |
| --- | --- |
| Kind | Community security standard |
| Issued or overseen by | Open Worldwide Application Security Project, GenAI Security Project |
| Jurisdiction | Global |
| Status | First edition 2023; 2025 edition current |

## 2. What it sets

2.1. The 2025 list: prompt injection; sensitive information disclosure; supply chain; data and model poisoning; improper output handling; excessive agency; system prompt leakage; vector and embedding weaknesses; misinformation; unbounded consumption. Each with its causes, examples, and mitigations.

## 3. Whom it reaches

3.1. Anyone who builds or buys an application on a language model. It is guidance, used by security teams, testers, and auditors.

## 4. Relevance to the Bank

4.1. It names the attacks that are new with generative AI and that a bank's security function must learn to test for, above all injection, leakage, and excessive agency in AI agents.

## 5. How the charter relates to it

5.1. The security test against attacks on AI in the validation of Risk Tier 2 and 3 Solutions, and the guardrails of a Solution, are built against this list; the risks of the Responsible AI course follow it.
