# Privacy

## 1. Scope

1.1. This statement describes what this site, the charter portal of the AI Competence Center ("AICC") of the Bank, does with information about the persons who use it. It applies to every page of the site.

1.2. The policies of the Bank on personal data, information security, and the acceptable use of its systems apply to the use of this site and prevail over this statement.

## 2. What the site collects

2.1. The site is a set of static pages. It has no accounts, no forms, no analytics, and no tracking, and it sends no request to any service outside the hosting of the site by the Bank.

2.2. The site sets no cookies. When a user chooses a theme with the button in the header, the site stores that one preference in the local storage of the browser. The preference is not sent anywhere, and the user removes it by clearing the site data in the browser.

2.3. The access gateway of the Bank through which the site is reached keeps its own sign-in session and may set a cookie for that purpose. The gateway is operated under the policies of the Bank, and the site does not read it.

2.4. The server that hosts the site keeps technical access logs for its security and operation, as the rules of the Bank for its systems provide.

## 3. Feedback and contact

3.1. The feedback and contact links open the mail program of the user with a message addressed to the mailbox of AICC, with the identifier of the page in the subject. Nothing is sent until the user sends the message.

3.2. A message that a user sends is internal correspondence of the Bank. It is used to answer the user and to improve the site and the documents, and it is kept as the rules of the Bank for correspondence provide.

## 4. Persons named on the site

4.1. The documents on this site name Roles, not persons. The persons who hold the Roles are recorded in the Appointments Record of the Registry, which is not part of this site.

4.2. The contact address of the site is a work mailbox of the Bank.

## 5. Questions and concerns

5.1. A question about this statement goes to the contact address in the footer. A concern about personal data is raised under the procedure of the Bank for personal data, with the Control Function Contact for data protection.

## 6. Revision

6.1. This statement is revised with the site. The revision of the site is stated in the footer of every page.
