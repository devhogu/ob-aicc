# Автоматизация рабочего места

Повседневная работа подразделения, которую выполняет AI, а проверяет работник: маршрутизация запросов, чтение и заполнение форм, обработка отчётов, консолидация входящих данных и подготовка документов по шаблонам. Ассистент готовит материал; работник проверяет его и решает, как поступить.

## 1. Содержание категории

1.1. Категория охватывает автоматизацию в инструментах, которыми подразделение уже пользуется: классификацию и маршрутизацию запросов и сообщений, извлечение данных из форм и их заполнение, обработку и обобщение отчётов, консолидацию входящих данных из нескольких источников, подготовку типовых документов по шаблонам на основе собранных сведений и помощь в работе с обращениями в пределах ограниченных полномочий.

1.2. У каждой автоматизации есть работник, который проверяет её результат до того, как он вступит в силу; глубина проверки соразмерна категории риска. Автоматизация, которая совершала бы действия в информационных системах или с денежными средствами без проверки, к этой категории не относится.

## 2. Примеры запросов подразделений

Ниже приведены примеры, поясняющие категорию; это не перечень обязательств. Обязательства Центра Компетенций устанавливаются в соглашении о взаимодействии по каждому взаимодействию с заказчиком.

- Классификация и маршрутизация запросов, жалоб и сообщений
- Извлечение данных из форм и документов, заполнение форм
- Обработка и обобщение регулярных отчётов; классификация расхождений, выявленных при сверке
- Консолидация входящих данных из нескольких источников в один рабочий файл
- Документы по шаблонам на основе собранных сведений для проверки работником
- Помощь в работе с обращениями в пределах ограниченных полномочий: выявление связанных обращений, предложение допустимого следующего шага, подготовка объяснения с опорой на источники

## 3. Результаты для подразделения

3.1. Работающие автоматизации — у каждой есть описание решения, категория риска, этап проверки результата и ответственный в подразделении; краткое руководство для пользователей; запись в каталоге автоматизаций, чтобы другое подразделение могло использовать автоматизацию повторно.

## 4. Порядок работы

4.1. Текущие работы: потребность поступает через единую точку входа, её объём определяют за несколько дней, автоматизацию создают за одну итерацию вместе с экспертом направления, она проходит проверку и передаётся подразделению. Набор автоматизаций для целого процесса — инициатива, которая начинается с изучения.

## 5. Ожидаемый эффект

5.1. Высвобождается время для более ценной работы, результаты становятся единообразнее, а каталог автоматизаций, которые подразделения используют повторно, пополняется.

## 6. Пакет

6.1. Каталог автоматизаций: каждая автоматизация — пакет с коннекторами, запросами к модели и правилами, этапом проверки результата и указаниями по развёртыванию.

## 7. Режим

7.1. Текущие работы — для отдельных автоматизаций; инициатива — для процесса.

## 8. Полномочия по принятию решений

8.1. Применение для соответствующего класса данных одобряет владелец направления; результат проверяет ответственный в подразделении; категорию риска присваивает руководитель Центра Компетенций.
