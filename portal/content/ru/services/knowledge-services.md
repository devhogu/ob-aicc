# Сервисы знаний

Документы подразделения, а также документы государственных и надзорных органов, с которыми оно работает, превращаются в управляемую базу знаний, к которой подразделение может обращаться с вопросами. Подразделения по правовым вопросам, комплаенсу, бухгалтерскому учёту, операционной деятельности и любые другие подразделения, у которых есть корпус документов, получают ассистента. Он отвечает по утверждённым актуальным источникам со ссылками на них — для работников подразделения и, если подразделение так решит, для его клиентов.

## 1. Содержание категории

1.1. Категория охватывает ведение корпуса документов с назначенными ответственными и установленной периодичностью пересмотра; загрузку документов подразделения, а также актов, нормативных документов и циркуляров органов, которым оно подотчётно; ассистента, который отвечает на вопросы по корпусу со ссылками на источники; инструменты поиска и запросов; управление источниками, чтобы ответы оставались актуальными, а их происхождение можно было проследить.

1.2. База знаний создаётся для одного подразделения с расчётом на повторное использование в других: тот же комплект средств, тот же порядок управления источниками, другой корпус документов. Общие базы знаний для нескольких подразделений создаются, когда эти подразделения работают с общим массивом документов.

## 2. Примеры запросов подразделений

Ниже приведены примеры, поясняющие категорию; это не перечень обязательств. Обязательства AICC устанавливаются в соглашении о взаимодействии по каждому взаимодействию с заказчиком.

- База знаний по процедурам и документам надзорного органа для подразделений по правовым вопросам, комплаенсу или бухгалтерскому учёту со ссылками на источники
- Общая база знаний для подразделений, которые работают с общим корпусом документов
- База ответов на запросы надзорного органа для подготовки отчётности надзорному органу
- Подсказки из базы знаний для оператора контактного центра непосредственно во время звонка
- Инструменты запросов и поиска по корпусу документов подразделения и порядок управления источниками, который поддерживает корпус в актуальном состоянии

## 3. Результаты для подразделения

3.1. Систематизированный корпус документов, ассистент, который ссылается на источники, доступ с учётом классов данных, оценочный набор, показывающий качество ответов, и порядок управления источниками для поддержания актуальности. Для подразделения, которое обслуживает клиентов, — тот же ассистент на материалах, которые подразделение решит сделать доступными клиентам, по правилам Банка.

## 4. Порядок работы

4.1. На изучении продолжительностью одна итерация определяются состав корпуса, ответственные за документы и классы данных. На этапе MVP база создаётся на первом наборе документов, и вместе с экспертом домена её качество оценивается на оценочном наборе. После этого за источники отвечает подразделение; AICC эксплуатирует ассистента или передаёт его в соответствии с соглашением о взаимодействии.

## 5. Ожидаемый эффект

5.1. Экспертные знания на рабочем месте: единообразные ответы, соответствующие требованиям, сокращение срока адаптации новых сотрудников и знания организации, которые сохраняются при кадровых изменениях. На этой основе впоследствии работают AI-агенты.

## 6. Пакет

6.1. Комплект средств базы знаний: загрузка, управление источниками, поиск и извлечение информации, цитирование и оценка; комплект повторно развёртывается для каждого подразделения с его собственным корпусом документов.

## 7. Режим

7.1. Initiative — для новой базы знаний; текущие работы — для добавления набора источников в существующую базу.

## 8. Полномочия по принятию решений

8.1. Состав корпуса и аудиторию определяет владелец домена; классы данных согласуют представители контрольных функций; категорию риска присваивает руководитель AICC.
