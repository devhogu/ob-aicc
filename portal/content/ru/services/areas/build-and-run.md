# Разработка и эксплуатация

Решения и платформы: знания, к которым подразделение может обращаться с вопросами; повседневная работа, которую выполняет AI, а проверяет работник; фактическая основа для управленческих решений; материалы, которые публикует подразделение; общие программные компоненты и среды, на которых всё это работает.

## 1. Категории направления

| Категория | Охват | Режим |
| --- | --- | --- |
| [Сервисы знаний](../knowledge-services.md) | Документы подразделения, а также документы государственных и надзорных органов, с которыми оно работает, в виде управляемой базы знаний, к которой подразделение может обращаться с вопросами | Инициатива — для новой базы знаний; текущие работы — для добавления набора источников в существующую базу |
| [Автоматизация рабочего места](../workplace-automation.md) | Маршрутизация, формы, отчёты, консолидация данных, документы по шаблонам и помощь в работе с обращениями; работу выполняет AI, результат проверяет работник | Текущие работы — для отдельных автоматизаций; инициатива — для процесса |
| [Аналитика и поддержка принятия решений](../analytics-and-decision-support.md) | Конвейеры обработки данных, дашборды, аналитические материалы и исследовательские инструменты, которые готовят фактическую основу для управленческих решений, с подтверждённым происхождением данных из контролируемых источников | Текущие работы — для представления данных или консолидации; инициатива — для конвейера, который обеспечивает данными регулярный отчёт Банка |

1.1. Категория — направление, по которому Центр компетенций оказывает услуги; примеры приведены на странице категории. Обязательства Центра компетенций устанавливаются в соглашении о взаимодействии по каждому взаимодействию с заказчиком. Текущие работы — небольшой повторяющийся запрос, который выполняется в пределах одной итерации (п. 4.7 Бизнес-модели); инициатива начинается с исследования и бизнес-кейса.

## 2. Обращение подразделения к направлению

2.1. Подразделение обращается со своей потребностью к руководителю Центра компетенций в любой форме. В единой точке входа потребность оценивают по проблеме, которую она решает, объёму, предполагаемой категории риска и тому, отвечает ли ей уже пакет или решение из каталога. Категория услуг определяет предлагаемый режим — текущие работы или инициатива, — а руководитель Центра компетенций его подтверждает (п. 7.2 Бизнес-модели). Шаги, обязательства и уровни поддержки описаны на странице «Порядок взаимодействия с Центром компетенций по AI», режимы — на странице «Режимы и единая точка входа» раздела «Портфель решений».

## 3. Результаты работы направления

3.1. По итогам взаимодействия с заказчиком в этом направлении остаются выводы и, если он сформирован, пакет — например, методика, комплект средств, программный компонент или запись каталога. С таким пакетом следующее подразделение получает результат за дни, тогда как первому потребовались недели (п. 4.4 Бизнес-модели). Форма описания пакета и записи каталога установлена на странице «Каталог услуг: форма»; сами пакеты хранятся в портфеле.
