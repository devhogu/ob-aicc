# Каталог услуг: форма

Каталог AICC перечисляет то, что AICC эксплуатирует, поставил, испытывает и может повторно развернуть. Эта страница устанавливает форму Каталога: два вида записей, поля каждого вида, а также состояние или статус каждой записи. Действующий Каталог — экземпляр этой формы, хранящийся в Портфеле AICC (Бизнес-модель 4.4); сайт устанавливает только форму (Каталог документов 5.4). Для иллюстрации приведено по одной записи каждого вида.

## 1. Два вида записей

1.1. Запись Решения описывает одно Решение AICC по его Описанию решения: Эксперимент, Продукт или Сервис. Запись Пакета описывает один Пакет, оставшийся по итогам Взаимодействия с заказчиком, по его Описанию пакета (Шаблон AICC-TPL-14): методику, комплект средств, программный механизм, каталог автоматизаций, набор шаблонов.

1.2. Решение служит своему заказчику; Пакет — следующему Взаимодействию с заказчиком. Вторая функция получает Пакет за дни там, где первое Взаимодействие с заказчиком заняло недели. Каталог Решений и Пакетов позволяет небольшому подразделению обслуживать весь Банк.

## 2. Поля записи Решения

| Поле | Значение | Источник |
| --- | --- | --- |
| Идентификатор | SOL-nnn, неизменный на протяжении жизненного цикла Решения | Описание решения |
| Название | Наименование Решения | Описание решения |
| Категория | Категория услуг, в рамках которой оно поставлено | Соглашение о взаимодействии |
| Тип | Эксперимент, Продукт или Сервис | Описание решения |
| Состояние и Стадия | Состояние по Модели жизненного цикла решений 5 и, после поставки, Стадия соответствующего типа | Описание решения; Портфель |
| Инициатива | Инициатива, которая его поставляет | Бэклог портфеля |
| Домен и Владелец Домена | Функция-заказчик и её представитель | Соглашение о взаимодействии |
| Получатель | Кто эксплуатирует или внедряет его после поставки; для Эксперимента — кто принимает Передачу | Описание решения |
| Категория риска | 1, 2 или 3 | Реестр AI |
| Уровень поддержки | Без поддержки, по запросу, с согласованными целевыми сроками реакции, эксплуатация AICC | Соглашение о взаимодействии |
| Состояние обслуживания | Четыре сигнала — уровни обслуживания, инциденты, использование и затраты — на последнем обзоре | Service Management; текущий обзор |

## 3. Поля записи Пакета

| Поле | Значение |
| --- | --- |
| Пакет | Наименование Пакета |
| Что делает | В одной-двух строках |
| Вид | Методика, комплект средств, программный механизм, каталог, набор шаблонов |
| Направление и Категория услуг | Категория услуг, которая создаёт и использует Пакет, с указанием Направления услуг |
| Статус | Запланирован, подготавливается, доступен или отозван; это статус, а не состояние элемента работы |
| Владелец | Инженер решений или Руководитель AICC, который его сопровождает |
| Используется | Функции и Решения, которые его используют |
| Необходимо для повторного развёртывания | Что должна предоставить новая функция: корпус документов, источник данных, набор шаблонов, владельца |
| Место хранения | Репозиторий или папка |

## 4. Состояние записи Решения и статус записи Пакета

4.1. Запись Решения следует состояниям Модели жизненного цикла решений 5.1: «Предложено», «Проработка» и «Одобрено» до поставки; «В работе» — от начала поставки до завершения жизненного цикла со Стадиями соответствующего типа после поставки; «Закрыто» — при выводе из эксплуатации, передаче или завершении (Модель жизненного цикла решений 8.1). Приёмки фиксируются в Разделе о Выпуске Описания решения. У записи Пакета есть статус, а не состояние: «запланирован», когда категория предполагает его создание; «подготавливается», когда он создаётся в рамках Взаимодействия с заказчиком; «доступен», когда у него есть владелец, описание и указания для повторного развёртывания; либо «отозван».

## 5. Иллюстрации

5.1. Запись Решения из Портфеля на дату базовой редакции:

| Идентификатор | Название | Тип | Состояние | Инициатива | Домен |
| --- | --- | --- | --- | --- | --- |
| SOL-001 | Конвейер подготовки финансовой отчётности FP&A для Совета директоров | Будет определён в MVP | Предложено | INI-004 FP&A: отчётность по финансовым показателям для Совета директоров | FP&A |

5.2. Запись Пакета:

| Пакет | Что делает | Вид | Категория | Статус | Используется |
| --- | --- | --- | --- | --- | --- |
| Генератор портала | Формирует портал из комплекта нормативных документов: разделы, документы по частям, ссылки на пункты, перекрёстные ссылки, определённые термины, схемы, поиск, два языка | Программный механизм | Платформы | Доступен | AICC — для этого сайта |

## 6. Источник правил

Модель жизненного цикла решений 5 и 8; Бизнес-модель 4.4 и 5.5; Каталог документов 5.4; Шаблоны Описания решения и Описания пакета (AICC-TPL-14).
