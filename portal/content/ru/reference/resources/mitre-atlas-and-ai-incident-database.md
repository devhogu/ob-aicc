# MITRE ATLAS и AI Incident Database

Две базы знаний, которые следует знать банку, применяющему AI. ATLAS систематизирует методы, которые злоумышленники применяют против систем AI, в виде матрицы, знакомой специалистам по безопасности по методологии атак MITRE, и содержит разборы реальных случаев. AI Incident Database собирает общедоступные сведения о вреде, причинённом системами AI, и об их сбоях, чтобы другие могли сделать выводы и не повторять чужих ошибок.

## 1. Общие сведения

| Параметр | Содержание |
| --- | --- |
| Вид | База знаний по безопасности; общедоступная база данных инцидентов |
| Организация | ATLAS — MITRE, некоммерческая организация, управляющая исследовательскими центрами; AI Incident Database — Responsible AI Collaborative совместно с Partnership on AI |
| Доступ | Бесплатно |

## 2. Публикации

2.1. ATLAS: тактики и методы атак на системы машинного обучения и AI — промпт-инъекция, извлечение модели, отравление данных, уклонение от обнаружения — с разборами случаев и мерами противодействия, сопоставленные с терминами перечня OWASP. AI Incident Database: инциденты из общедоступных источников, классифицированные по виду вреда, отрасли и системе, с таксономией и порядком подачи сообщений.

## 3. Значение для Банка

3.1. Для тестирования защищённости решения категории риска 2 или 3 от атак, специфичных для AI, нужна модель угроз, и ATLAS даёт для неё терминологию. Разбор инцидента AI в Банке учитывает выводы из чужих инцидентов; база данных — место, где они собраны, в том числе инциденты в финансовом секторе.

## 4. Порядок и цели использования

4.1. Для моделирования угроз до начала разработки и для тестирования защищённости ATLAS используют вместе с перечнем OWASP: какие методы применимы к этому решению и какие меры противодействия уже действуют. Для защитных механизмов лабораторной среды и для разбора инцидента AI изучают инциденты из базы данных в финансовом секторе и в обслуживании клиентов и задаются вопросом, может ли такой же сбой произойти в Банке. ATLAS используют подразделение информационной безопасности и проверяющий; руководитель Центра Компетенций использует базу данных при ежеквартальной проверке рисков.

## 5. Меры предосторожности

5.1. ATLAS описывает атаки; применять его методы к любой системе можно только с разрешения, которого требуют правила Банка. База данных содержит общедоступные сообщения разного качества; инцидент воспринимается так, как о нём сообщено, а не как установленный факт.
