# arXiv и Papers with Code

Репозиторий, где исследования AI впервые появляются в виде препринтов — до рецензирования и нередко вместо него, — и указатель, связывающий статью с её кодом, наборами данных и заявленными результатами. Это первоисточники для изучения метода и проверки утверждений поставщика или публикации.

## 1. Сведения

| Параметр | Содержание |
| --- | --- |
| Вид | Репозиторий препринтов и указатель исследований |
| Организация | arXiv под управлением Корнеллского университета — для препринтов; Papers with Code — поддерживаемый сообществом указатель, связывающий статьи с кодом и результатами |
| Доступ | Бесплатно |

## 2. Что публикует

2.1. arXiv: препринты по AI, компьютерной обработке языка, машинному обучению и компьютерному зрению с поиском и ежедневными списками публикаций. Papers with Code: те же статьи со ссылками на реализации, наборы данных и рейтинги результатов по задачам.

## 3. Значение для Банка

3.1. Когда поставщик или публикация заявляет о методе или результате, статья служит свидетельством, а код и рейтинг результатов помогают проверить утверждение. Инженер решений, проектирующий поиск или оценку, изучает метод в исходной публикации. Представитель контрольной функции, проводящий Валидацию модели, может прочитать, что о ней опубликовали разработчики.

## 4. Как и для чего использовать

4.1. Для проверки утверждения следует найти статью и прочитать раздел оценки и ограничения. Для изучения метода — читать статью вместе с кодом. Для понимания состояния задачи — внимательно изучать рейтинг результатов. Лучше следить за несколькими категориями или авторами, чем за всем ежедневным потоком. Категория услуг AICC «Исследования и изучение возможностей» ведёт мониторинг и готовит обзоры значимых материалов.

## 5. Ограничения и меры предосторожности

5.1. Препринт не прошёл рецензирование и может содержать ошибки; результаты на эталонных тестах не переносятся на задачи Банка без оценки на этих задачах. Читать можно свободно; никакие материалы или данные Банка не передаются.
