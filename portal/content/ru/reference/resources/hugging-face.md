# Hugging Face: открытые модели, наборы данных и документация

Репозиторий, в котором публикуются открытые модели и наборы данных с документацией, лицензиями и карточками моделей, а также собственная документация компании и курс по работе с ними. Для инженера решений это место, где находят и оценивают открытую модель; для остальных — место, где видна открытость отрасли.

## 1. Общие сведения

| Параметр | Содержание |
| --- | --- |
| Вид | Платформа и сообщество открытого машинного обучения |
| Организация | Hugging Face — компания; репозиторий открыт для всех, большую часть материалов размещает сообщество |
| Доступ | Бесплатно; для некоторых функций нужна регистрация; платные вычислительные ресурсы есть, но для чтения они не нужны |

## 2. Публикации

2.1. Репозиторий моделей и наборов данных с карточками, лицензиями и результатами оценки; документация библиотек, которыми пользуется большая часть открытой экосистемы; бесплатный курс по языковым моделям и инструментам для работы с ними; открытые рейтинги для сравнения моделей; блог компании о методах и новых версиях.

## 3. Значение для Банка

3.1. Открытые модели — вариант, который Банк будет рассматривать ради затрат, локализации данных и контроля, и именно в репозитории их сравнивают. Карточка модели — тот документ, который изучается при оценке поставщика в Банке. Документация служит справочником по методам поиска и извлечения информации и дообучения.

## 4. Порядок и цели использования

4.1. Для оценки открытых моделей следует изучить карточки и рейтинги, а затем протестировать отобранные модели в лабораторной среде на оценочном наборе Банка. Метод изучают по документации и курсу. При оценке поставщика открытой модели исходными подтверждающими материалами служат указанные в карточке лицензия, сведения об обучающих данных и известные ограничения.

## 5. Меры предосторожности

5.1. Большую часть материалов размещает сообщество; карточка модели — это заявление её автора, и прежде чем на него полагаться, его сверяют. Лицензия изучается до использования. Открытая модель, которая обрабатывает данные Банка, является поставщиком в смысле Политики применения AI, где бы она ни работала, и проходит проверку поставщика и тестирование защищённости. Никакие материалы Банка в репозиторий не загружаются.
