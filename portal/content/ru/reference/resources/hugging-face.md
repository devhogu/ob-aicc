# Hugging Face: открытые модели, наборы данных и документация

Репозиторий открытых моделей и наборов данных с документацией, лицензиями и карточками моделей, а также собственные документация и курс компании по их применению. Для Инженера решений это место поиска и оценки открытой модели; для остальных — наглядное представление открытости отрасли.

## 1. Сведения

| Параметр | Содержание |
| --- | --- |
| Вид | Платформа и сообщество открытого машинного обучения |
| Организация | Hugging Face — компания; репозиторий общедоступен, большая часть материалов предоставлена сообществом |
| Доступ | Бесплатно; для некоторых функций требуется регистрация; платные вычислительные ресурсы существуют, но для чтения не нужны |

## 2. Что публикует

2.1. Репозиторий моделей и наборов данных с карточками, лицензиями и оценками; документация библиотек, используемых большей частью открытой экосистемы; бесплатный курс по языковым моделям и инструментам; открытые рейтинги сравнения моделей; блог компании о методах и выпусках.

## 3. Значение для Банка

3.1. Банк будет рассматривать открытые модели с учётом стоимости, размещения данных и контроля, а репозиторий позволяет их сравнивать. Карточка модели — форма, изучаемая при оценке поставщика Банком. Документация служит справочным источником по методам поиска и дообучения.

## 4. Как и для чего использовать

4.1. Для оценки открытых моделей следует изучить карточки и рейтинги, затем проверить кандидатов в Лабораторной среде на собственном Оценочном наборе Банка. Для изучения метода — использовать документацию и курс. При оценке поставщика открытой модели исходными свидетельствами служат лицензия, сведения об обучающих данных и известные ограничения в карточке.

## 5. Ограничения и меры предосторожности

5.1. Большинство материалов предоставляет сообщество; карточка модели содержит заявления автора, которые проверяются до использования в качестве основания. Лицензия изучается до применения. Открытая модель, обрабатывающая данные Банка, является Поставщиком в смысле Политики применения AI независимо от места запуска и проходит проверку поставщика и проверку безопасности. Никакие материалы или данные Банка не загружаются в репозиторий.
