# Всемирный экономический форум об управлении ИИ и финансовых услугах

Площадка, где отрасль, регуляторы и гражданское общество формулируют совместные позиции по ИИ и будущему финансовых услуг в докладах для советов директоров. Альянс по управлению ИИ публикует подходы к ответственному генеративному ИИ; направление финансовых услуг — материалы о преобразовании банковской деятельности.

## 1. Сведения

| Параметр | Содержание |
| --- | --- |
| Вид | Международная организация государственно-частного сотрудничества; доклады и практические руководства |
| Организация | Всемирный экономический форум через Альянс по управлению ИИ, Центр четвёртой промышленной революции и платформу финансовых услуг |
| Доступ | Бесплатно; доклады на сайте |

## 2. Что публикует

2.1. Доклады Альянса по управлению ИИ о безопасной разработке, развёртывании и управлении генеративным ИИ с аналитическими записками для руководителей; практические руководства для советов директоров и по ответственному применению ИИ; доклады платформы финансовых услуг об ИИ, данных и будущем отрасли; Доклад о глобальных рисках, включающий ИИ в ранжируемые риски.

## 3. Значение для Банка

3.1. Материалы Форума формируют общий язык советов директоров и руководителей по вопросам ИИ; с изложенной там позицией могли ознакомиться Комитет Совета директоров и инвесторы Банка. Подход Форума к управлению генеративным ИИ согласуется с принципами Банка и полезен для их внешнего сопоставления.

## 4. Как и для чего использовать

4.1. Для представления вопросов на уровне Совета директоров следует использовать записки для руководителей и практические руководства для советов директоров. Для межотраслевых позиций по управлению генеративным ИИ — читать доклады Альянса и сопоставлять с Заявлением о намерениях. Для понимания отрасли — читать доклады о финансовых услугах как позицию, сформированную совместно с её участниками.

## 5. Ограничения и меры предосторожности

5.1. Доклады Форума создаются совместно с компаниями-участниками, включая крупные технологические и консалтинговые компании; отраслевые позиции следует воспринимать именно как позиции. Материалы не являются нормативными актами и не налагают обязательств.
