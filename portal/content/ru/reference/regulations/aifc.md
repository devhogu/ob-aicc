# Международный финансовый центр «Астана»

Финансовый центр в Казахстане с собственной юрисдикцией, судами и органом регулирования, действующий на принципах общего права. Его правила в области финансовых услуг, защиты данных и технологий, а также регуляторная «песочница» для финтеха влияют на практику в регионе.

## 1. Общие сведения

| Параметр | Содержание |
| --- | --- |
| Вид | Финансовый центр с собственной системой регулирования |
| Издатель или надзорный орган | Международный финансовый центр «Астана» (МФЦА) и его Комитет по регулированию финансовых услуг |
| Юрисдикция | Казахстан |
| Статус | Создан в 2018 году; собственные правила в области финансовых услуг, данных и технологий; регуляторная «песочница» для финтеха |

## 2. Содержание

2.1. Правила лицензирования и ведения деятельности для участников центра; правила защиты данных; регуляторная «песочница» для финтеха и для испытания новых услуг; рекомендации по технологиям и цифровым активам.

## 3. Сфера применения

3.1. Участники центра и лица, которые с ними взаимодействуют.

## 4. Значение для Банка

4.1. Региональный центр, правила и «песочница» которого служат ориентиром для практики финтеха и для организации экспериментов в регулируемой среде; возможная площадка для партнёров Банка.

## 5. Связь с корпусом нормативных документов

5.1. Рабочий процесс эксперимента и лабораторная среда AICC построены на той же идее испытания в установленных пределах, которая лежит в основе регуляторной «песочницы».
