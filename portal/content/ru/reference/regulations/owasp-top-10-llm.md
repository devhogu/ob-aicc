# OWASP Top 10 для приложений на основе больших языковых моделей

Перечень десяти наиболее значимых рисков приложений на основе больших языковых моделей, составленный сообществом специалистов по безопасности. Его поддерживает проект, создавший наиболее известный перечень рисков безопасности веб-приложений. Это ориентир для проверки безопасности Решения ИИ.

## 1. Сведения

| Параметр | Содержание |
| --- | --- |
| Вид | Стандарт безопасности, разрабатываемый профессиональным сообществом |
| Издающий или надзорный орган | Open Worldwide Application Security Project, GenAI Security Project |
| Юрисдикция | Международный уровень |
| Статус | Первое издание — 2023 год; актуальное издание — 2025 год |

## 2. Что устанавливает

2.1. Перечень 2025 года: внедрение вредоносных инструкций в запросы; раскрытие чувствительной информации; риски цепочки поставок; отравление данных и моделей; ненадлежащая обработка выходных данных; избыточная самостоятельность; утечка системного запроса; уязвимости векторов и эмбеддингов; недостоверная информация; неограниченное потребление ресурсов. Для каждого риска приведены причины, примеры и меры снижения.

## 3. На кого распространяется

3.1. Все, кто разрабатывает или приобретает приложение на основе языковой модели. Рекомендации используются подразделениями безопасности, специалистами по тестированию и аудиторами.

## 4. Значение для Банка

4.1. Перечень определяет атаки, появившиеся с генеративным ИИ, которые функция безопасности банка должна научиться выявлять при проверках, прежде всего внедрение вредоносных инструкций, утечки и избыточную самостоятельность агентов.

## 5. Связь с корпусом нормативных документов

5.1. Проверка безопасности в отношении атак на ИИ при Валидации Решений Категорий риска 2 и 3, а также защитные механизмы Решения строятся с учётом этого перечня; ему следует и описание рисков в курсе «Ответственный ИИ».
