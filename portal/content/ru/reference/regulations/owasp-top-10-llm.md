# OWASP Top 10 для приложений на основе больших языковых моделей

Перечень десяти наиболее значимых рисков приложений на основе больших языковых моделей, составленный сообществом специалистов по безопасности. Его ведёт проект, который создал самый известный перечень рисков безопасности веб-приложений. Это эталон для тестирования защищённости AI-решения.

## 1. Общие сведения

| Параметр | Содержание |
| --- | --- |
| Вид | Стандарт безопасности, разработанный профессиональным сообществом |
| Издатель или надзорный орган | Open Worldwide Application Security Project (OWASP), проект GenAI Security Project |
| Юрисдикция | Глобальная |
| Статус | Первое издание — 2023 год; действующее издание — 2025 год |

## 2. Содержание

2.1. Перечень 2025 года: промпт-инъекция; раскрытие конфиденциальной информации; риски цепочки поставок; отравление данных и модели; ненадлежащая обработка выходных данных; избыточная самостоятельность; утечка системного запроса; уязвимости векторов и эмбеддингов; недостоверная информация; неограниченное потребление ресурсов. Для каждого риска приведены причины, примеры и меры снижения.

## 3. Сфера применения

3.1. Все, кто разрабатывает или приобретает приложение на основе языковой модели. Перечень носит рекомендательный характер; им пользуются подразделения безопасности, тестировщики и аудиторы.

## 4. Значение для Банка

4.1. Перечень называет атаки, появившиеся вместе с генеративным AI, тестировать которые подразделению информационной безопасности банка предстоит научиться, — прежде всего промпт-инъекции, утечки и избыточную самостоятельность AI-агентов.

## 5. Связь с корпусом нормативных документов

5.1. Тестирование защищённости от атак на AI при валидации решений категорий риска 2 и 3 и защитные механизмы решения построены с опорой на этот перечень; по нему же построено описание рисков в курсе «Ответственный AI».
