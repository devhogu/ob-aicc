Русские HTML-страницы формируются из этих источников: тексты документов, пояснения, названия, навигация, таблицы, подписи схем и поиск используют русский язык. Названия продуктов и организаций, идентификаторы, имена файлов и адреса сохраняют исходную форму. Ни один язык не имеет установленного приоритета; расхождения согласуются по решениям и истории изменений.
