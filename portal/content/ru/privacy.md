# Конфиденциальность

## 1. Область применения

1.1. Настоящее заявление описывает обращение этого сайта — портала Центра компетенций по AI («AICC») Банка, называемого Порталом AICC, — с информацией о его пользователях. Оно распространяется на все страницы сайта на обоих языках.

1.2. К использованию сайта применяются политики Банка о персональных данных, информационной безопасности, классификации информации и допустимом использовании систем; они имеют приоритет перед настоящим заявлением. Сайт входит в перечень инструментов и порталов AICC Workflow совместной работы корпуса документов; к нему применяются правила Операционной модели о содержании инструментов.

## 2. Что собирает сайт

2.1. Сайт представляет собой набор статических страниц. На нём нет учётных записей, форм, аналитики или отслеживания; он не направляет запросов к сервисам за пределами инфраструктуры размещения сайта Банка. Поиск выполняется в браузере по индексу, входящему в состав сайта; поисковый запрос нигде не сохраняется и никуда не отправляется.

2.2. Сайт не устанавливает файлы cookie. Когда пользователь выбирает тему кнопкой в заголовке, сайт сохраняет только эту настройку в локальном хранилище браузера. Настройка никуда не передаётся; пользователь удаляет её, очищая данные сайта в браузере. Кнопки копирования записывают данные только в буфер обмена устройства пользователя.

2.3. Шлюз доступа Банка, через который открывается сайт, ведёт собственный сеанс входа и может устанавливать для него файл cookie. Шлюз эксплуатируется по политикам Банка; сайт не читает этот файл.

2.4. Сервер размещения сайта ведёт технические журналы доступа для безопасности и эксплуатации согласно правилам Банка для своих систем. Сайт хранится в репозитории с управлением версиями; история публикаций сохраняется и не содержит сведений о читателях.

## 3. Обратная связь и контакты

3.1. Ссылки обратной связи и контактов открывают почтовую программу пользователя с сообщением на адрес AICC, идентификатором страницы в теме и её названием и адресом в тексте. Ничего не отправляется до отправки пользователем; он видит всё сообщение и может его изменить.

3.2. Отправленное пользователем сообщение является внутренней перепиской Банка. Оно используется для ответа пользователю и улучшения сайта и документов и хранится по правилам Банка для переписки.

## 4. Ссылки с сайта

4.1. Сайт содержит ссылки на корпус нормативных документов и Реестр на Корпоративном сетевом ресурсе Банка. Эти ссылки открываются только в сети Банка с правами доступа к ресурсу; их открытие не передаёт сайту сведений. Сайт не содержит ссылок на внешние по отношению к Банку сайты; внешние источники в Справочнике названы так, чтобы читатель мог их найти, а их посещение регулируется правилами Банка.

## 5. Лица, упоминаемые на сайте

5.1. Документы и страницы сайта называют Роли, а не конкретных лиц. Исполнители Ролей указаны в Записи о назначениях Реестра, которая не входит в этот сайт. Контактный адрес сайта — рабочий почтовый ящик Банка.

5.2. Сайт не содержит числовых показателей Банка, данных Банка, клиентов или сотрудников либо кода Банка, как требует Операционная модель 7.8 для Портала AICC.

## 6. Вопросы и обращения

6.1. Вопрос по настоящему заявлению направляется на контактный адрес внизу страницы. Обращение по персональным данным подаётся по процедуре Банка с участием Представителя контрольной функции защиты данных.

## 7. Пересмотр

7.1. Заявление пересматривается вместе с сайтом и как минимум при ежегодном пересмотре корпуса нормативных документов. Редакция сайта указана внизу каждой страницы.
