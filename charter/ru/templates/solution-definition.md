# Описание решения

**Шаблон.** Описание решения оформляется по каждому решению при его определении. Описание заполняют инженер решений и эксперт направления, категорию риска присваивает руководитель Центра компетенций, описание одобряет владелец направления. Если решение создано руководителем Центра компетенций, описание одобряет и категорию риска присваивает куратор Центра компетенций. В описании указываются объём, методы и архитектура решения. Описание не содержит числовых показателей Банка, данных и кода и составляется кратко, по единой форме.
