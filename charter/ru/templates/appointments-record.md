# Запись о назначениях

**Шаблон.** Соответствие Ролей и обязанностей корпуса Положения конкретным людям с журналом назначений. Эта Актуализируемая запись называет Исполнителей Ролей; корпус Положения называет только Роли. В Часть C разрешено только добавление записей. Части A и B формируются на её основе. Снимок Реестра при каждом закрытии Итерации сохраняет датированную выгрузку. Запись содержит имена и должности Исполнителей Ролей, их декларации, согласия и доступ, без иных персональных данных. Другие Записи могут называть лицо ответственным за элемент; Исполнитель Роли фиксируется здесь.

## Часть B. Ответственность

RACI по действиям с одной подотчётной Ролью на каждое действие приведена в Руководстве по организации. Исполнители из Части A связывают каждую Роль с человеком. Применяются правила разделения полномочий Операционной модели 4.4. Совмещения, допустимые при малой Команде по Бизнес-модели 7.5 и Модели жизненного цикла решений 7.3(d), перечисляются здесь как Принятые ограничения, каждое с компенсирующими контрольными мерами, включая ежемесячную выборку Управленческих решений Руководителя AICC. Каждое Принятое ограничение также учитывается в Записи о рисках и проблемах по идентификатору RI.
