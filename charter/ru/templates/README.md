# Шаблоны

Шаблоны устанавливают формы записей, которые ведёт AICC. Шаблон задаёт форму записи в реестре или портфеле; правила ведения записей установлены документами. Перечень шаблонов приведён в разделе 6 Каталога документов. Шаблон копируется начиная с заголовка, без блока метаданных (п. 6.1 Каталога документов). Шаблоны расположены в порядке применения: работа по инициативе начинается с первого шаблона, а взаимодействие с заказчиком завершается восьмым. Описание пакета оформляется, если пакет предусмотрен категорией услуг или создан по итогам взаимодействия с заказчиком, и поддерживается в актуальном состоянии, пока пакет доступен. Шаблоны «Запись о назначениях», «Снимок реестра», «Квартальный отчёт» и «Предложение» применяются в собственном цикле.
