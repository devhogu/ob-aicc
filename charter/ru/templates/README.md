# Шаблоны

Формы Записей, которые создаёт AICC. Шаблон задаёт форму Записи в Реестре или Портфеле; правила установлены документами. Перечень приведён в Каталоге документов 6. Копируйте Шаблон начиная с заголовка, без блока метаданных (Каталог документов 6.1). Шаблоны расположены в порядке применения: Инициатива начинается с первого, Взаимодействие с заказчиком завершается восьмым. Описание пакета открывается, если Пакет предусмотрен категорией услуги или получен по результатам Взаимодействия с заказчиком, и поддерживается актуальным, пока Пакет доступен. Запись о назначениях, Снимок Реестра, Квартальный отчёт и Предложение используются в собственных циклах.
