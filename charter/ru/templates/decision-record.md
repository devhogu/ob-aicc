# Запись о решении

**Шаблон.** Запись о решении — подтверждающая запись об управленческом решении, которое в соответствии с пунктом 5.6 и разделом 8 Операционной модели оформляется записью о решении. В журнале решений каждой записи о решении соответствует одна строка. Запись не содержит числовых показателей Банка, данных и кода и составляется кратко.

| Поле | Содержание |
| --- | --- |
| Идентификатор | DR-[yyyy]-[nnn] |
| Наименование | [действие и предмет] |
| Дата | [дата] |
| Вид | [труднообратимое управленческое решение куратора AICC / проверка документов (п. 7.1 Каталога документов) / соглашение об обмене данными / отступление от требований, предоставленное руководителем AICC / одобрение публикуемого результата AI / переход / одобрение бизнес-кейса / управленческое решение по итогам MVP / выпуск решения категории риска 3 / риск сверх риск-аппетита / стратегические приоритеты, инвестиционные бюджеты или инвестиционные ограничения / риск-аппетит либо пересмотр документов / управленческое решение по предложению] |
