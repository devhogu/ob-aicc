# Протокол решения

**Шаблон.** Протокол решения — подтверждающий документ об управленческом решении, которое в соответствии с пунктом 5.6 и разделом 8 Операционной модели оформляется протоколом решения. В журнале решений каждому протоколу решения соответствует одна строка. Протокол не содержит числовых показателей Банка, данных и кода и составляется кратко.

| --- | --- |

| Наименование | [действие и предмет] |
| Дата | [дата] |
| Вид | [труднообратимое управленческое решение куратора Центра компетенций / проверка документов (п. 7.1 Каталога документов) / соглашение об обмене данными / отступление от требований, предоставленное руководителем Центра компетенций / одобрение публикуемого результата AI / переход / одобрение бизнес-кейса / управленческое решение по итогам MVP / выпуск решения категории риска 3 / риск сверх риск-аппетита / стратегические приоритеты, инвестиционные бюджеты или инвестиционные ограничения / риск-аппетит либо пересмотр документов / управленческое решение по предложению] |
