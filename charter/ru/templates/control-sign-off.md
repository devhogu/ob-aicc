# Заключение контрольной функции

**Шаблон.** Заключение контрольной функции фиксирует управленческое решение представителя контрольной функции: валидацию, остановку применения решения, проверку поставщика, отступление от требований или согласование бизнес-кейса. Если в валидации участвуют несколько представителей, каждый оформляет отдельное заключение. Заключение не содержит числовых показателей Банка, данных и кода.

| Поле | Содержание |
| --- | --- |
| Идентификатор | SGN-[nnn] |
| Вид | [валидация / остановка применения / проверка поставщика / отступление от требований / согласование бизнес-кейса] |
| Предмет | [SOL-nnn, INI-nnn — для бизнес-кейса, либо поставщик] |
| Область действия | [на что распространяется заключение] |
| Контрольная функция и её представитель | [функция, ФИО] |
| Подтверждённая категория риска | [категория 1, 2 или 3 — присвоенная либо ожидаемая согласно бизнес-кейсу; или иная категория с указанием причины (п. 3.2 Политики применения AI); рассматривался ли вопрос об отнесении к категории высокого риска] |
| Заключение | [валидация пройдена / валидация пройдена с условиями / применение остановлено / отступление от требований предоставлено / отказано / согласовано / не согласовано / категория риска повышена] |
| Дата | [дата] |
| Срок действия | [дата либо изменение, при котором требуется новое заключение; для отступления от требований — срок его действия (п. 6.1 Политики применения AI)] |
| Позиция записи о рисках и проблемах | [RI-nnn — для отступления от требований] |
| Условия и цели, для которых применение не допускается | [каждое условие с указанием ответственного и даты] |
| Основания | [ссылки] |
