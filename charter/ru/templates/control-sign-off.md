# Заключение контрольной функции

**Шаблон.** Решение Представителя контрольной функции: Валидация, остановка, проверка Поставщика, Исключение либо согласование экономического обоснования. Если в Валидации участвует несколько Представителей, каждый оформляет отдельное заключение. Не содержит числовых показателей Банка, данных или кода.

| Поле | Значение |
| --- | --- |
| Идентификатор | SGN-[nnn] |
| Тип | [Валидация / остановка / проверка Поставщика / Исключение / согласование экономического обоснования] |
| Предмет | [SOL-nnn, INI-nnn для экономического обоснования либо Поставщик] |
| Область действия | [что охватывает решение] |
| Контрольная функция и Представитель | [функция, имя] |
| Подтверждённая Категория риска | [Категория 1, 2 или 3 — присвоенная либо ожидаемая в экономическом обосновании; или другая Категория с причиной (Политика применения искусственного интеллекта 3.2); проверялось ли отнесение к категории высокого риска] |
| Решение | [Валидация пройдена / Валидация пройдена с условиями / остановлено / Исключение предоставлено / отказано / согласовано / не согласовано / Категория риска повышена] |
| Дата | [дата] |
| Действует до | [дата либо изменение, требующее нового решения; для Исключения — дата истечения срока (Политика применения искусственного интеллекта 6.1)] |
| Запись о рисках и проблемах | [RI-nnn для Исключения] |
| Условия и запреты на применение | [каждое условие с ответственным и датой] |
| Основание | [ссылки] |
