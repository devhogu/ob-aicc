A [[project-profile|project profile]] is a ready-made description of a type of work: when it fits, what stages it has, and what is usually checked in it. A profile is a pattern; a real project is run on a [[project-card|card]] that names its profile. The [[practice-checklist|practice checklist]] in each profile is a prompt, not a requirement: each project checks it against its own rules.
