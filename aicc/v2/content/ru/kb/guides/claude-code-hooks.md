Указание в `CLAUDE.md` — это просьба: Claude обычно её выполняет, но может и упустить. Хук — это гарантия: ваша команда запускается автоматически в определённый момент, без исключений.

## Главные моменты для хуков {#events}

| Момент | Когда срабатывает |
| --- | --- |
| `SessionStart` | начало или возобновление сеанса |
| `UserPromptSubmit` | вы отправили запрос, Claude его ещё не обработал |
| `PreToolUse` | перед действием Claude — может его заблокировать |
| `PostToolUse` | после успешного действия |
| `Notification` | Claude ждёт вашего ответа или разрешения |
| `Stop` | Claude закончил ответ |
| `PreCompact` / `PostCompact` | до и после сжатия контекста |

## Как настроить {#setup}

Проще всего попросить Claude: «Напиши хук, который запускает форматирование после каждой правки» или «Напиши хук, который запрещает запись в папку migrations». Настроенные хуки видны по команде `/hooks`; хранятся они в `.claude/settings.json`.

Хук получает описание события в формате JSON, а ответить может кодом выхода: `0` — продолжать, `2` — заблокировать с сообщением для Claude.

## Предосторожности {#safety}

- Хук — это команда на вашей машине с вашими правами. Читайте каждый хук, прежде чем включать, особенно чужой.
- Проверяйте пути и экранируйте входные данные: хук получает то, что прислал Claude.
- Если хук должен видеть *все* изменения файлов, учтите, что Claude может менять файлы и через команды оболочки, а не только правками.
