Несколько минут настройки делают каждую следующую сессию заметно лучше. Вот что настраивать и в каком порядке.

## CLAUDE.md — короткая памятка проекта {#claude-md}

Claude читает этот файл в начале каждой сессии. Создайте заготовку командой `/init` и доводите её со временем. Для каждой строки спрашивайте себя: «Если её убрать, Claude начнёт ошибаться?» Если нет — удаляйте.

| Включать | Не включать |
| --- | --- |
| Команды сборки и тестов, которые нельзя угадать | То, что видно из кода |
| Правила стиля, отличные от обычных | Общеизвестные правила языка |
| Как называть ветки и оформлять PR | Подробную документацию API (лучше ссылка) |
| Решения по архитектуре, особенности окружения | Часто меняющиеся сведения, длинные объяснения |

Если Claude упорно нарушает правило из файла — скорее всего, файл слишком длинный и правило теряется. Храните `CLAUDE.md` в git: он становится ценнее со временем.

## Разрешения {#permissions}

В ручном режиме Claude спрашивает перед правками и командами; в автоматическом — новые версии начинают с него — действия проверяет отдельная модель и блокирует рискованные. В обоих режимах полезно заранее разрешить безопасное — запуск линтера, тестов — командой `/permissions` и включить изолированную среду через `/sandbox`. Для чувствительного кода выбирайте ручной режим: так каждое действие проходит через вас, а нажимать «да» вслепую не придётся.

## Что выбрать для повторяющегося {#extend}

<div class="rai-cards rai-cards--4">
<article><h3>Навык</h3><p>Знания и процедуры, нужные иногда: <code>.claude/skills/имя/SKILL.md</code>. Claude подключает сам или по команде <code>/имя</code>.</p></article>
<article><h3>Помощник</h3><p>Отдельный исполнитель со своим контекстом и инструментами — например, ревьюер безопасности: <code>.claude/agents/</code>.</p></article>
<article><h3>Хук</h3><p>Скрипт, который выполняется каждый раз без исключений: проверка после правки, запрет записи в папку.</p></article>
<article><h3>Подключения (MCP)</h3><p>Доступ к трекеру задач, базе данных, документации — командой <code>claude mcp add</code>, если разрешено.</p></article>
</div>

Правило выбора: `CLAUDE.md` — то, что нужно всегда; навык — то, что нужно иногда; хук — то, что должно происходить обязательно.

## Безопасность {#safety}

Не кладите в `CLAUDE.md`, навыки и запросы пароли, ключи и токены. Подключайте только одобренные инструменты и смотрите изменения (`git diff`) перед коммитом.
