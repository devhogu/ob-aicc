Анализ доли рынка и конкурентного позиционирования показывает, какое место Банк занимает по продуктам, сегментам и регионам среди банков и небанковских компаний, которые конкурируют за отношения с теми же клиентами. Он охватывает количественную сторону (доля на рынке депозитов, место по размеру кредитного портфеля, позиция по объёму операций по картам) и качественную: в чём, по мнению целевых сегментов, Банк отличается от конкурентов, а в чём нет. На многих рынках конкурентную позицию определяют крупные банки с давно сложившимся доминирующим положением, растущее присутствие цифровых банков-челленджеров и конкуренция в трансграничных платежах. **Генеративный AI позволяет непрерывно отслеживать конкурентные сигналы** — публичная отчётность, данные регулятора и новости сводятся в аналитику о конкурентной позиции, на которую раньше уходили недели работы аналитиков.

## Доля рынка по продуктам {#market-share-by-product}

Доля Банка на каждом продуктовом рынке — розничных депозитов, потребительского кредитования, ипотеки, кредитования МСБ, корпоративного финансирования, операций по картам — по отношению к общему объёму рынка по данным регулятора и отраслевых ассоциаций. Доля рынка по продуктам — основной результат анализа конкурентной позиции: она показывает, где Банк наращивает позиции, где сохраняет их и где уступает сопоставимым банкам и небанковским альтернативам. Главный источник — статистика банковского сектора, которую публикует регулятор; обычно она выходит с задержкой в несколько недель.

### Мониторинг доли рынка по продуктам

- Аспект: Автоматизация
- Сложность: S
- Назначение: AI-агент отслеживает публикации данных регулятора, при каждом выходе извлекает статистику банковского сектора по продуктам и готовит для руководства по стратегии и по работе с инвесторами (IR) аналитическую записку о доле рынка.
- Решаемая задача: Данные регулятора выходят по нерегулярному графику, и прежде чем руководство увидит картину доли рынка, их нужно вручную извлечь, сравнить с показателями сопоставимых банков и описать. На каждую публикацию уходит два-три рабочих дня аналитика, и результат часто готов позже, чем он нужен стратегическому подразделению.
- Решение: AI-агент отслеживает график публикаций регулятора, при каждом выходе извлекает нужную статистику по продуктам, рассчитывает позицию Банка в сравнении с группой сопоставимых банков и готовит аналитическую записку о доле рынка для руководства по стратегии и IR. Руководитель стратегического направления подтверждает записку, и комментарий о рыночной позиции в материалах для Совета директоров берётся непосредственно из результата, подготовленного AI-агентом.
- Критерии приёмки: Аналитическая записка о доле рынка по продуктам, подготовленная по данным регулятора в день их публикации, доступна руководству по стратегии и IR не позднее 24 часов после выхода каждой новой публикации.

| Измерение | Ключевой результат |
| --- | --- |
| Внедрение | С даты запуска AI-агент обрабатывает ≥95% значимых публикаций данных регулятора и готовит записку о доле рынка не позднее 24 часов после публикации. |
| Принятие | ≥80% записок руководитель стратегического направления подтверждает как точные по существу и готовые к распространению без повторного ручного анализа. |
| Цикл | Подготовка записки о доле рынка сокращается с двух-трёх рабочих дней аналитика на ручное извлечение данных регулятора и написание комментария до ≤24 часов автоматического извлечения и проверки результата AI-агента. |

### Справка о разрыве с целевой долей рынка

- Аспект: Поддержка
- Сложность: S
- Назначение: AI-агент сравнивает текущую долю рынка по продуктам с целевыми значениями стратегического плана, рассчитывает текущий разрыв в объёмах и доходах и готовит справку к ежеквартальному обзору коммерческих результатов.
- Решаемая задача: Целевые значения доли рынка по продуктам устанавливаются в стратегическом плане раз в год. Чтобы понять, идёт ли Банк в текущем году по плану, опережает его или отстаёт, нужно сопоставить последнюю публикацию регулятора с внутренним планом портфеля, а между годовыми циклами планирования этого не делают. Коммерческое руководство управляет продуктовым портфелем, не имея постоянной картины разрыва с целями.
- Решение: AI-агент обрабатывает каждую новую публикацию данных регулятора, сравнивает текущую долю Банка по продуктам с целевыми значениями стратегического плана, рассчитывает разрыв в объёмах и доходах и готовит справку к ежеквартальному обзору коммерческих результатов. Вместо того чтобы заказывать разовый анализ, коммерческое руководство включает подготовленную AI-агентом справку в повестку обзора постоянным пунктом о разрыве с целями.
- Критерии приёмки: К ежеквартальному обзору коммерческих результатов постоянно готовится справка о разрыве с целями: текущая доля рынка по продуктам сравнивается с целевыми значениями стратегического плана, разрыв выражен в объёмах и доходах.

| Измерение | Ключевой результат |
| --- | --- |
| Внедрение | AI-агент готовит справку о разрыве с целями к ≥95% ежеквартальных обзоров коммерческих результатов на протяжении ≥4 кварталов подряд после запуска; охвачены все продукты, по которым установлена стратегическая целевая доля. |
| Принятие | ≥80% справок коммерческое руководство принимает как постоянный материал к повестке без дополнительно заказанного анализа. |
| Цикл | Разрыв с целями виден не раз в год, в цикле планирования, а ежеквартально: справка обновляется не позднее пяти рабочих дней с даты каждой публикации данных регулятора. |

### Анализ динамики доли рынка по продуктам

- Аспект: Аналитика
- Сложность: M
- Назначение: AI-агент анализирует динамику доли рынка по продуктам в последовательных публикациях данных регулятора, выявляет продукты, по которым Банк статистически значимо наращивает или теряет долю, и готовит обзор тенденций для коммерческого руководства и руководства по стратегии.
- Решаемая задача: Данные регулятора о доле рынка по продуктам рассматриваются при каждой публикации как статичный срез. Чтобы увидеть тенденцию — устойчиво ли Банк наращивает или теряет долю в потребительском кредитовании или розничных депозитах на протяжении 6–8 периодов, — нужно вести и сопоставлять исторические данные, а между годовыми циклами планирования такой анализ в стандартную практику не входит.
- Решение: AI-агент ведёт скользящий набор данных о доле продуктов по последовательным публикациям регулятора, рассчитывает по каждому продукту направление тенденции и её статистическую значимость и готовит обзор, в котором статистически значимые изменения доли отделены от случайных колебаний. Коммерческое руководство и руководство по стратегии рассматривают отмеченные тенденции, а коммерческие подразделения в первую очередь направляют инвестиции и корректируют цены по продуктам, у которых снижение доли подтверждено.
- Критерии приёмки: Коммерческое руководство и руководство по стратегии при каждой публикации данных регулятора получают обзор тенденций: продукты, по которым Банк статистически значимо наращивает или теряет долю, причём эти изменения отделены от случайных колебаний.

| Измерение | Ключевой результат |
| --- | --- |
| Внедрение | С даты запуска AI-агент ведёт скользящий набор данных о доле продуктов и готовит обзор тенденций по ≥95% публикаций данных регулятора. |
| Принятие | ≥80% отмеченных тенденций коммерческое руководство и руководство по стратегии при рассмотрении подтверждают как существенные. |
| Цикл | Динамика доли по продуктам анализируется не в годовых циклах планирования, а при каждой публикации регулятора: обзор готов не позднее пяти рабочих дней с даты публикации. |

## Сравнение продуктов с конкурентами {#peer-product-benchmarking}

Систематическое сравнение характеристик продуктов, тарифных планов и условий обслуживания Банка с группой сопоставимых банков. На его основе принимаются решения об обновлении продуктов; оно показывает, где Банку не хватает функций и где его цены уязвимы. Сравнение должно охватывать всех конкурентов: крупные государственные банки, частные отечественные банки, дочерние банки иностранных групп и цифровые банки-челленджеры. На многих рынках среди цифровых конкурентов уже есть необанки, работающие только через мобильное приложение, с тарифами, которые выигрывают у традиционных банков прозрачностью комиссий.

### Мониторинг ценовой позиции

- Аспект: Автоматизация
- Сложность: S
- Назначение: Автоматический ежемесячный отчёт о ценовой позиции Банка по основным розничным продуктам в сравнении с группой сопоставимых банков — ставки по депозитам и потребительским кредитам, комиссии по картам. Отчёт готовится без ручного сбора ставок и рассматривается продуктовыми подразделениями и тарифным комитетом.
- Решаемая задача: Ценовую позицию Банка в сравнении с сопоставимыми банками собирают казначейство и группа ценообразования продуктов: ставки вручную берут с сайтов конкурентов и из отзывов сотрудников отделений, и на каждую категорию продуктов в каждом цикле уходит один-два дня. Порядок работы систематически не задокументирован, и когда нужных сотрудников нет на месте, в охвате появляются пробелы. Тарифный комитет рассматривает вопросы при неполной картине по конкурентам.
- Решение: AI-агент ежемесячно собирает общедоступные сведения о ставках и комиссиях сопоставимых банков, строит сравнение ценовой позиции по основным розничным продуктам Банка и готовит ежемесячный ценовой мониторинг для тарифного комитета. Группа ценообразования сверяет мониторинг с опубликованными источниками, и комитет рассматривает полное и единообразно составленное сравнение с конкурентами, а не собранный вручную и, возможно, неполный обзор ставок.
- Критерии приёмки: Тарифный комитет ежемесячно получает мониторинг ценовой позиции: ставки Банка по депозитам и потребительским кредитам и комиссии по картам в сравнении с группой сопоставимых банков, собранные из опубликованных сведений о ставках и комиссиях без ручного сбора.

| Измерение | Ключевой результат |
| --- | --- |
| Внедрение | AI-агент готовит ценовой мониторинг для ≥95% плановых ежемесячных циклов на протяжении ≥12 месяцев подряд после запуска; по каждому основному розничному продукту охвачено ≥90% установленной группы сопоставимых банков. |
| Принятие | При выборочной сверке ≥90% ставок и комиссий конкурентов подтверждаются опубликованными источниками; в ≥85% циклов тарифный комитет принимает мониторинг без дополнительного сбора ставок. |
| Цикл | Сбор ставок конкурентов сокращается с одного-двух дней на категорию продуктов в каждом цикле до ≤2 часов проверки группой ценообразования. |

### Сравнение характеристик продуктов с конкурентами

- Аспект: Аналитика
- Сложность: M
- Назначение: AI-агент ежеквартально собирает общедоступные сведения о характеристиках и ценах продуктов сопоставимых банков, строит структурированную матрицу сравнения по основным розничным продуктам и продуктам для МСБ и показывает, где Банку не хватает функций и где его цены уязвимы.
- Решаемая задача: Стратегические и продуктовые подразделения сравнивают продукты с конкурентами разово и вручную: просматривают сайты конкурентов, читают годовые отчёты, следят за пресс-релизами. Подходы различаются по продуктам и подразделениям, сравнение не обновляется с установленной периодичностью, и отставание от конкурентов накапливается незаметно. Цифровые необанки часто меняют условия продуктов ежеквартально, и ручной мониторинг за ними не успевает.
- Решение: AI-агент ежеквартально анализирует общедоступные страницы продуктов, тарифы и пресс-релизы сопоставимых банков, сводит данные в матрицу сравнения характеристик основных розничных продуктов и продуктов для МСБ и отмечает, где Банку не хватает функций или где его цены выходят за диапазон конкурентов. Продуктовые и стратегические подразделения работают со сравнением, подготовленным AI-агентом, и не заказывают ручное исследование.
- Критерии приёмки: Продуктовые и стратегические подразделения ежеквартально получают матрицу сравнения характеристик основных розничных продуктов и продуктов для МСБ с продуктами сопоставимых банков; функции, которых Банку не хватает, и цены вне диапазона конкурентов отмечены.

| Измерение | Ключевой результат |
| --- | --- |
| Внедрение | AI-агент готовит матрицу сравнения для ≥90% плановых ежеквартальных циклов на протяжении ≥4 кварталов подряд после запуска; охвачены все основные розничные продукты и продукты для МСБ. |
| Принятие | При выборочной сверке ≥85% позиций матрицы подтверждаются публичными источниками конкурентов; ≥75% отмеченных пробелов продуктовые и стратегические подразделения признают значимыми. |
| Цикл | Продукты сравниваются с конкурентами не в разовых ручных исследованиях, а ежеквартально: матрица готова не позднее двух недель после окончания квартала. |

### Мониторинг цифровых банков-челленджеров

- Аспект: Аналитика
- Сложность: M
- Назначение: AI-агент отслеживает изменения в продуктах, ценах и цифровом клиентском опыте цифровых необанков на рынке Банка и ежеквартально готовит для руководства цифрового и продуктового направлений обзор действий этих конкурентов.
- Решаемая задача: Мониторинг конкурентов сосредоточен на традиционных банках, публичная отчётность которых структурирована и предсказуема. Цифровые банки-челленджеры — необанки, работающие только через мобильное приложение, без сети отделений и с минимальным обязательным раскрытием информации, — меняют условия продуктов и цифровые функции нерегулярно, и систематически за этим никто не следит. О значимых шагах таких конкурентов продуктовые подразделения узнают из отзывов клиентов или из прессы, а не в ходе заблаговременного мониторинга.
- Решение: AI-агент ежемесячно отслеживает страницы продуктов, карточки приложений в магазинах приложений, страницы тарифов и пресс-релизы цифровых банков-челленджеров на рынке Банка, классифицирует изменения по категориям продуктов и значимости и готовит ежеквартальный обзор. По этому обзору руководство цифрового и продуктового направлений оценивает, требуют ли действия конкурентов ответных продуктовых решений в текущем цикле планирования.
- Критерии приёмки: Руководство цифрового и продуктового направлений ежеквартально получает обзор действий цифровых банков-челленджеров в продуктах, ценах и цифровом клиентском опыте, составленный по итогам ежемесячного мониторинга их страниц продуктов, карточек в магазинах приложений, страниц тарифов и пресс-релизов.

| Измерение | Ключевой результат |
| --- | --- |
| Внедрение | AI-агент проводит ежемесячный мониторинг цифровых банков-челленджеров в ≥95% плановых циклов и готовит ежеквартальный обзор на протяжении ≥4 кварталов подряд после запуска. |
| Принятие | ≥80% изменений, отнесённых к значимым, руководство цифрового и продуктового направлений при ежеквартальном рассмотрении подтверждает как значимые. |

## Доля рынка по сегментам {#market-share-by-segment}

Доля рынка в разбивке по клиентским сегментам — массовый розничный сегмент, клиенты с растущим достатком, микробизнес, основной сегмент МСБ, корпоративные клиенты — показывает, где позиция Банка устойчива, а где его присутствие ниже стратегических приоритетов. Долю по сегментам измерить сложнее: данные регулятора приводятся по продуктам, а не по сегментам, поэтому их приходится сочетать с оценками клиентских исследований и данными о структуре собственного портфеля. Пока автоматической сборки нет, стратегические подразделения оценивают долю по сегментам по ежегодным заказным исследованиям.

### Отчёт о доле рынка по сегментам

- Аспект: Автоматизация
- Сложность: S

Главное препятствие для более частой подготовки — сведение и оформление данных.

Руководство по стратегии получает картину по сегментам каждый квартал; аналитическую работу, которая мешала готовить отчёт чаще, выполняет AI-агент, а не аналитики.
- Критерии приёмки: Руководство по стратегии ежеквартально получает отчёт о доле рынка по сегментам, в котором внутренние данные портфеля и статистика регулятора сведены по единой методике без ручной сборки.

### Модель оценки доли рынка по сегментам

- Аспект: Аналитика
- Сложность: M
- Назначение: AI-агент сочетает данные регулятора по продуктам, оценки клиентских исследований и структуру внутреннего портфеля и ежеквартально оценивает долю рынка по сегментам, чтобы у руководства по стратегии и коммерческого руководства постоянно была картина позиций по сегментам.
- Решаемая задача: Доля рынка по сегментам оценивается раз в год по заказным исследованиям. Между исследованиями руководители по стратегии и коммерческие руководители работают с оценками давностью от 6 до 18 месяцев. Публикуемые регулятором данные по продуктам и структура внутреннего портфеля позволили бы получать косвенную оценку чаще, но систематически их не сводят.
- Решение: AI-агент берёт статистику банковского сектора по продуктам, которую публикует регулятор, и данные о структуре внутреннего портфеля Банка, применяет модель восстановления структуры сегментов, откалиброванную по последнему заказному исследованию, и ежеквартально оценивает долю рынка в массовом розничном сегменте, среди клиентов с растущим достатком, в микробизнесе и в основном сегменте МСБ. Руководство по стратегии каждый квартал получает косвенную оценку; ежегодное заказное исследование перестаёт быть единственным источником и используется для проверки и перекалибровки модели.
- Критерии приёмки: Руководство по стратегии и коммерческое руководство ежеквартально получают косвенную оценку доли рынка по сегментам — массовый розничный сегмент, клиенты с растущим достатком, микробизнес и основной сегмент МСБ, — выведенную из данных регулятора по продуктам и откалиброванную по последнему заказному исследованию.

### Анализ разрыва с целевой долей по сегментам

- Аспект: Аналитика
- Сложность: M
- Назначение: AI-агент сравнивает оценки доли Банка по сегментам со стратегическими приоритетами, выявляет сегменты, где текущая доля существенно ниже стратегической цели, и выражает разрыв в числе клиентов и в доходах.
- Решаемая задача: Стратегические приоритеты по сегментам задаются в годовом плане через целевую долю рынка по каждому сегменту. Разрыв между текущей и целевой долей — коммерческое расстояние, которое нужно преодолеть, — рассматривается раз в год при обновлении плана и в течение года не отслеживается. Коммерческие подразделения не видят, сокращается или растёт по ходу года разрыв, например, по доле в основном сегменте МСБ.
- Решение: AI-агент сопоставляет ежеквартальную оценку доли по сегментам с целевой долей каждого сегмента в стратегическом плане, рассчитывает текущий разрыв в числе клиентов и в доходах и готовит отчёт для коммерческого руководства и руководства по стратегии. Коммерческая программа корректируется ежеквартально с учётом того, как меняется разрыв, а не только по итогам годового пересмотра плана.
- Критерии приёмки: Коммерческое руководство и руководство по стратегии ежеквартально получают отчёт, в котором по каждому сегменту показано расстояние между текущей оценкой доли и стратегической целью в числе клиентов и в доходах.

| --- | --- |
| Внедрение | AI-агент готовит отчёт о разрыве для ≥90% плановых ежеквартальных циклов на протяжении ≥4 кварталов подряд после запуска; охвачены все сегменты, по которым установлена стратегическая целевая доля. |
| Принятие | ≥80% отчётов коммерческое руководство и руководство по стратегии принимают как основу для ежеквартальной корректировки программы. |

## Стратегические действия конкурентов {#competitor-strategic-moves}

Мониторинг и обобщение стратегических заявлений, сделок слияния и поглощения (M&A), сведений в базах регулятора и сигналов из коммуникаций с инвесторами сопоставимых банков. Этот уровень анализа показывает, на что конкуренты делают стратегические ставки, до того как результат отразится в данных о доле рынка. О стратегических шагах конкурентов становится известно из биржевых сообщений банков, акции которых обращаются на бирже, из публикаций регулятора и пресс-релизов. Чтобы свести эти сигналы, нужно собирать данные из многих источников, и большинство стратегических подразделений делает это вручную и непоследовательно.

### Мониторинг сведений о конкурентах в базах регулятора

- Аспект: Автоматизация
- Сложность: S
- Назначение: AI-агент отслеживает базы данных регулятора, выявляет значимые сведения о конкурентах — заявления на получение лицензий, уведомления о крупных сделках, меры воздействия — и передаёт эти сведения стратегическому подразделению не позднее 48 часов после публикации.
- Решаемая задача: Сведения о конкурентах — заявления на получение лицензий на новые продукты, уведомления о значимых сделках и меры воздействия — появляются в базах регулятора нерегулярно. Стратегические подразделения не отслеживают эти базы постоянно, и о значимых событиях у конкурентов узнают только из прессы или на отраслевых мероприятиях.
- Решение: AI-агент ежедневно проверяет базы регулятора, выявляет сведения о сопоставимых банках, превышающие порог значимости (заявления на получение лицензий, уведомления о крупных сделках, меры воздействия), и не позднее 48 часов после публикации направляет стратегическому подразделению сводное уведомление. Стратегическое подразделение получает структурированные сведения о конкурентах из баз регулятора без ручного мониторинга.
- Критерии приёмки: Стратегическое подразделение получает сводное уведомление о значимых сведениях о сопоставимых банках в базах регулятора — заявлениях на получение лицензий, уведомлениях о крупных сделках, мерах воздействия — не позднее 48 часов после публикации и без ручного мониторинга баз.

| Измерение | Ключевой результат |
| --- | --- |
| Внедрение | С даты запуска AI-агент отслеживает базы регулятора в ≥98% рабочих дней и направляет уведомление не позднее 48 часов по ≥95% сведений выше порога значимости. |
| Принятие | ≥80% уведомлений стратегическое подразделение при ежемесячном рассмотрении подтверждает как значимые для конкурентной позиции. |
| Цикл | О значимых сведениях о сопоставимых банках становится известно не из прессы или на отраслевых мероприятиях, а не позднее 48 часов после публикации. |

### Оценка ответа на стратегический шаг конкурента

## Доля рынка по регионам {#geographic-market-share}

Доля рынка на уровне регионов и городов необходима для решений об инвестициях в сеть продаж, о приоритетах развития сети отделений и о порядке выхода в новые регионы. Региональная доля особенно важна там, где банковские услуги сосредоточены в крупнейших городах, а региональные рынки заметно недообслужены: банк, который первым вложится в региональную цифровую инфраструктуру, получает значительную возможность роста. Регуляторы, как правило, публикуют региональную банковскую статистику в составе стандартной отчётности по сектору.

### Автоматический отчёт о динамике региональной доли

- Аспект: Автоматизация
- Сложность: S
- Назначение: Автоматический отчёт о динамике доли Банка на региональных рынках по последовательным публикациям данных регулятора. Отчёт готовится без ручной сборки и после каждой публикации передаётся руководству по развитию сети продаж и руководству по стратегии.
- Решаемая задача: Чтобы отслеживать динамику региональной доли по последовательным публикациям регулятора, аналитику приходится вести исторический набор данных из отдельных выгрузок, приводить методику разных публикаций к единой и вручную писать комментарий о тенденциях. Трудозатраты растут с числом регионов и публикаций, и когда аналитиков не хватает, отчёт часто откладывают.
- Решение: AI-агент пополняет набор данных после каждой публикации регулятора, применяет единую методику ко всем публикациям и автоматически готовит отчёт о динамике региональной доли. Руководство по развитию сети продаж и руководство по стратегии получают комментарий о тенденциях, не заказывая ручной анализ; аналитики занимаются не сбором данных, а толкованием результатов.
- Критерии приёмки: Руководство по развитию сети продаж и руководство по стратегии после каждой публикации регулятора получают отчёт о динамике региональной доли рынка, построенный по постоянно пополняемому набору данных по единой методике и без ручной сборки.

| Измерение | Ключевой результат |
| --- | --- |
| Внедрение | С даты запуска AI-агент пополняет набор данных и готовит отчёт о региональной динамике по ≥95% публикаций регулятора; охвачены все регионы, приведённые в публикации. |
| Принятие | ≥85% отчётов руководство по развитию сети продаж и руководство по стратегии принимают без заказа дополнительного анализа. |
| Цикл | Отчёт о региональной динамике готовится не вручную, когда у аналитиков есть время, а не позднее пяти рабочих дней с даты каждой публикации. |

### Мониторинг доли рынка по регионам

- Аспект: Аналитика
- Сложность: M
- Назначение: AI-агент при каждой публикации извлекает из материалов регулятора региональную банковскую статистику, рассчитывает долю Банка по продуктам в каждом регионе и готовит обзор региональных позиций для руководства по стратегии и руководства по развитию сети продаж.
- Решаемая задача: Чтобы определить позицию Банка, данные регулятора о региональной доле рынка приходится вручную извлекать и сопоставлять с собственными региональными данными портфеля. Стратегические подразделения и подразделения развития сети заказывают такой анализ по мере необходимости — для презентаций Совету директоров или решений о региональных инвестициях; между этими событиями постоянной картины региональной доли нет.
- Решение: AI-агент отслеживает график публикаций регулятора, при выходе извлекает региональную банковскую статистику, сопоставляет её с региональными данными портфеля Банка и рассчитывает долю рынка по регионам и категориям продуктов. Руководство по стратегии и руководство по развитию сети продаж получают обзор региональных позиций не позднее одной недели после каждой публикации регулятора; решения о региональных инвестициях опираются на текущие данные о доле, а не на заказные исследования.
- Критерии приёмки: Руководство по стратегии и руководство по развитию сети продаж не позднее одной недели после каждой публикации регулятора получают обзор региональных позиций с долей рынка Банка по регионам и категориям продуктов.

### Обзор возможностей в недообслуженных регионах

- Аспект: Аналитика
- Сложность: M
- Назначение: AI-агент сочетает данные о региональной доле рынка, охвате населения банковскими услугами и демографии, выявляет регионы с наибольшим доступным потенциалом роста с учётом нынешнего присутствия Банка и готовит для руководства по стратегии обзор с ранжированием регионов для инвестиций.
- Решаемая задача: Решения о выходе в новые регионы опираются на качественное знание регионов и периодически заказываемые исследования. Систематическое сравнение разрывов в охвате банковскими услугами по регионам, текущей позиции Банка и доступной для привлечения аудитории с учётом уже сделанных инвестиций в сеть продаж в стандартный набор аналитики не входит. Стратегические подразделения не могут последовательно ранжировать региональные возможности по единой системе критериев.
- Решение: AI-агент берёт данные регулятора об охвате банковскими услугами по регионам, региональную статистику портфеля Банка и доступные демографические данные, рассчитывает для каждого региона оценку доступного потенциала по категориям продуктов и ранжирует регионы по ожидаемой отдаче в сравнении с затратами на развитие сети продаж. Руководство по стратегии берёт это ранжирование за исходную основу при определении приоритетов выхода в регионы.
- Критерии приёмки: Руководство по стратегии получает обзор с ранжированием регионов для инвестиций: регионы с наибольшим доступным потенциалом роста в сравнении с затратами на развитие сети продаж, оценённые по категориям продуктов по единой системе критериев.

| Измерение | Ключевой результат |
| --- | --- |
| Внедрение | С даты запуска AI-агент готовит ранжирование региональных возможностей для ≥90% плановых циклов планирования; охвачены все регионы, по которым опубликованы данные об охвате банковскими услугами. |
| Принятие | ≥70% регионов из верхней части ранжирования руководство по стратегии подтверждает как приоритетные при определении очерёдности выхода в регионы. |
| Цикл | Ранжирование региональных возможностей строится не на качественном знании регионов и периодических заказных исследованиях: обзор с ранжированием обновляется не позднее двух недель после каждой публикации регулятора. |
