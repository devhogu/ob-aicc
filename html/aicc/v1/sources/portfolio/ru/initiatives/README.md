# Инициативы

Для каждой инициативы ведётся отдельная папка, имя которой состоит из идентификатора INI-nnn и краткого наименования, например `INI-002-service-landscape-discovery/`. В папке хранятся паспорт инициативы (`brief.md`), соглашения о взаимодействии и отчёты о результатах по взаимодействию с заказчиком, а также Capabilities и Features инициативы.
