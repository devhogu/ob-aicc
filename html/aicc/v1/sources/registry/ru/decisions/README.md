# Протоколы решений

Протокол решения составляется по каждому труднообратимому управленческому решению куратора AICC и по каждому управленческому решению, подтверждающим документом которого согласно разделу 8 Операционной модели служит протокол решения. Протоколы решений индексируются в журнале решений. В папке хранятся протоколы решений, составленные по шаблону «Протокол решения». Протоколов решений пока не составлено.

Имя файла протокола решения состоит из его идентификатора и краткого наименования, например `DR-yyyy-nnn-short-title.md`. Идентификатор имеет вид DR-yyyy-nnn.
