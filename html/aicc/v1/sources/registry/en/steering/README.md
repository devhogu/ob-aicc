# Steering

The Steering Summaries, named by the date and the type, for example `2027-01-29-monthly.md` or `2027-03-26-quarterly.md`, from the Steering Summary Template. Only the matters, the advice, the Decisions, and the actions are kept. In the month that holds the IP week there is no separate monthly Steering, and the quarterly Steering is the Steering of that month (Operating Model 6.7), except in December, when the monthly Steering is held in the first two weeks as the yearly Steering, and its Summary is named with the type `yearly`.
