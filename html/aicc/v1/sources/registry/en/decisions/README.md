# Decisions

A Decision Record for each hard-to-reverse Decision of the Executive Sponsor and each Decision that the Operating Model 8 names as evidenced by one. The Decision Log indexes them. The folder holds the Decision Records, from the Decision Record Template. No Decision Record is recorded yet.

A Decision Record is named with its identifier and a short title, for example `DR-yyyy-nnn-short-title.md`. The identifier is DR-yyyy-nnn.
