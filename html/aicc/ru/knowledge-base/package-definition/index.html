Шаблон. Копируется для каждого Пакета, когда он предусмотрен категорией услуги или получен по результатам Взаимодействия с заказчиком. Владелец заполняет Описание при создании Пакета и поддерживает его актуальность, пока Пакет доступен; Руководитель AICC ведёт его в Портфеле (Бизнес-модель 4.4). Описание определяет, что представляет собой Пакет, что содержит и как функция повторно развёртывает его. Не содержит числовых показателей Банка, данных или кода. Излагайте кратко, в одной форме.
