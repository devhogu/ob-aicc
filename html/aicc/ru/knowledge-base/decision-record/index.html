Шаблон. Запись о решении — подтверждающая запись об управленческом решении, которое в соответствии с пунктом 5.6 и разделом 8 Операционной модели оформляется записью о решении. В журнале решений каждой записи о решении соответствует одна строка. Запись не содержит числовых показателей Банка, данных и кода и составляется кратко.

Поле Содержание
Идентификатор DR-[yyyy]-[nnn]
Наименование [действие и предмет]
Дата [дата]
Вид [труднообратимое управленческое решение куратора AICC / проверка документов (п. 7.1 Каталога документов) / соглашение об обмене данными / исключение, предоставленное руководителем AICC / одобрение публикуемого результата AI / переход / одобрение бизнес-кейса / управленческое решение по итогам MVP / выпуск решения категории риска 3 / риск сверх риск-аппетита / стратегические приоритеты, инвестиционные бюджеты или инвестиционные ограничения / риск-аппетит либо пересмотр документов / управленческое решение по предложению]
Уровень [руководитель AICC / куратор AICC / владелец направления]
Кем принято [роль, ФИО]
Статус [Принято / Заменено / Отменено]
Срок действия [дата — для исключения]
Позиция записи о рисках и проблемах [RI-nnn — для исключения]

1. Факты

[Факты, на которых основано управленческое решение, с указанием источников.]

3. Управленческое решение

[Содержание управленческого решения, его последствия и сфера действия: Банк, направление или решение.]

[Заявленные конфликты интересов, а также учтённые рекомендации с указанием, кем они даны.]

5. Канал принятия
