Шаблон. Руководитель AICC готовит отчёт каждый квартал к Ежеквартальному управляющему совещанию. Куратор AICC одобряет его. Отчёт не содержит числовых показателей Банка, данных или кода; числовые показатели приводятся по ссылкам.
