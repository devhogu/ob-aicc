Шаблон. Копируется для каждого Решения при его определении. Инженер решений и Эксперт Домена заполняют его, Руководитель AICC присваивает Категорию риска, Владелец Домена одобряет. Для Решения, созданного Руководителем AICC, Куратор AICC одобряет Описание и присваивает Категорию риска. Документ описывает Решение: объём, методы и архитектуру. Не содержит числовых показателей Банка, данных или кода. Излагайте кратко, в одной форме.
