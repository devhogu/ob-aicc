Постоянная инициатива «Контроль и оценка»

Для подразделений, у которых возникают небольшие повторяющиеся потребности по направлению услуг «Контроль и оценка», в рамках постоянной инициативы по каждому запросу фиксируются ответственный, приоритет, критерии приёмки и результат, а работа выполняется за одну итерацию. Ожидаемая выгода — оперативная и контролируемая поддержка без оформления отдельного паспорта инициативы и соглашения о взаимодействии по каждому запросу.

Лицо, принявшее решение, по протоколу DR-2026-063: Владелец базовой версии по зафиксированному указанию. Согласно п. 4.9 Бизнес-модели постоянную инициативу одобряет куратор Центра Компетенций; это одобрение ещё не зафиксировано.

Для каждой Feature необходимы подразделение-заказчик и владелец направления, критерии приёмки, известные зависимости, одобрение применения AI для соответствующего класса данных (если используется AI) и объём, укладывающийся в одну итерацию.

Собственный MVP не требуется; работа выполняется в виде Features текущих работ.
