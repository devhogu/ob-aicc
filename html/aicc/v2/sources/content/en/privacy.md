This page explains how the AI Competence Hub website handles information about its users. This statement covers every page of the site.

## What the site collects

The site is a set of ready-made pages. It has no user accounts, no forms, and no analytics or tracking tools, and it does not contact any service outside the infrastructure in which the organization hosts it.

- **Search.** Search runs in your browser, using an index that is part of the site. Your query is not sent anywhere and leaves no trace.
- **Cookies.** The site does not set any. If you choose a theme with the button in the site header, your choice is saved in your browser's local storage. It is not sent anywhere, and you can delete it by clearing the site's data in your browser.
- **Logs.** The server that hosts the site keeps technical access logs for security and operations, under the organization's rules. The site itself does not store any information about users.

## Feedback

Feedback links open your email program with a pre-filled message to the organization's work address. The subject line contains the page ID, and the body contains the page's title and address. Nothing is sent until you send it yourself; until then, you can see the whole message and edit it.

Once sent, the message becomes part of the organization's ordinary work correspondence. We use it to reply to you and to improve the site.

## Links

The site has no links to third-party resources other than the publicly available sources mentioned in the text, which are linked so that you can find them. Visiting them is subject to the organization's rules.

## People and data

The pages name roles and positions, not people. The site contains no customer or employee data, no confidential figures, and none of the organization's software code.
