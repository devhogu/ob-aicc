Почти все советы по Claude Code вытекают из одного ограничения: [[context-window|контекстное окно]] заполняется быстро — каждое сообщение, каждый прочитанный файл, каждый вывод команды. Чем оно полнее, тем чаще модель забывает ранние указания и ошибается. Контекст — главный ресурс, которым нужно управлять.

## 1. Дайте способ проверить работу {#verify}

Claude останавливается, когда работа *выглядит* готовой. Дайте ему проверку, которая отвечает «да/нет»: тесты, сборку, линтер, скриншот для сравнения. Тогда он сам доводит работу до результата.

| Слабее | Сильнее |
| --- | --- |
| «напиши проверку email» | «напиши validateEmail; примеры: user@example.com — верно, user@.com — неверно; запусти тесты после реализации» |
| «сборка падает» | «сборка падает с этой ошибкой: […]. Исправь причину, а не подавляй ошибку, и проверь, что сборка проходит» |

Просите показывать доказательства: вывод тестов, команду и её результат.

## 2. Сначала разобраться, потом план, потом код {#plan}

Режим планирования (Plan mode, переключается Shift+Tab) позволяет Claude читать и отвечать, ничего не меняя. Порядок: изучить код → составить план → реализовать → закоммитить. Для мелочей вроде опечатки план не нужен: если изменение описывается одним предложением — просто попросите его сделать.

## 3. Точный контекст в запросе {#context}

Назовите файл, сценарий и способ проверки; укажите на похожий код как образец; опишите симптом, вероятное место и что значит «исправлено». Файлы можно указывать через `@`, скриншоты — вставлять прямо в запрос.

## 4. Держите сессию чистой {#session}

- `Esc` — остановить Claude и поправить курс; `Esc Esc` или `/rewind` — откатиться к прошлой точке.
- `/clear` — между несвязанными задачами.
- Поправили дважды, а всё не то? `/clear` и новый, более точный запрос — почти всегда лучше длинной сессии с исправлениями.
- Большие исследования поручайте помощникам (subagents): они читают файлы в своём контексте и приносят только выводы.

## Пять типичных ошибок {#mistakes}

<div class="rai-cards rai-cards--3">
<article><h3>Сессия «обо всём»</h3><p>Разные задачи в одном разговоре засоряют контекст. Лечится <code>/clear</code>.</p></article>
<article><h3>Исправления по кругу</h3><p>После двух неудачных правок — чистый лист и лучший запрос.</p></article>
<article><h3>Раздутый CLAUDE.md</h3><p>Слишком длинный файл — важные правила теряются. Сокращайте.</p></article>
<article><h3>Поверил — не проверил</h3><p>Правдоподобный код без проверки краевых случаев. Нет проверки — не выпускайте.</p></article>
<article><h3>Бесконечное исследование</h3><p>«Изучи всё» без рамок съедает контекст. Сужайте задачу или отдайте её помощнику.</p></article>
</div>
