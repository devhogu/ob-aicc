Claude Code — ассистент для работы с кодом, который запускается в терминале прямо в папке проекта. Он читает файлы, предлагает и вносит изменения, запускает команды и тесты. По сути это [[ai-agent|AI-агент]] для разработки, поэтому правило то же, что для любого агента: он действует, а вы контролируете.

Пользуйтесь им только с одобренным в вашей организации аккаунтом и на тех репозиториях, где это разрешено.

## Первый запуск {#start}

1. Откройте терминал в папке репозитория.
2. Запустите `claude` и войдите под рабочим аккаунтом.
3. Начните с вопроса, а не с изменения: «Расскажи, как устроен этот проект и где точка входа».
4. Создайте файл `CLAUDE.md` командой `/init`: в нём ассистент кратко описывает проект, а вы дописываете правила — как собирать, как запускать тесты, что не трогать.

## Как давать задачу {#task}

- **Одна задача — один шаг.** «Добавь проверку пустого значения в функцию X и тест на это».
- **Говорите, как проверить.** «Запусти тесты и покажи результат».
- **Ссылайтесь на файлы.** Укажите путь к файлу или функции, о которой речь.
- **Просите план для большого.** «Сначала предложи план, ничего не меняя».

## Контроль {#control}

- Узнайте, в каком режиме разрешений вы работаете. В ручном режиме Claude спрашивает перед каждой правкой и командой — читайте, что он собирается сделать, прежде чем согласиться. В новых версиях по умолчанию включён автоматический режим: действия проверяет отдельная модель и останавливает рискованные. Для чувствительных репозиториев выбирайте ручной режим.
- Работайте в отдельной ветке и смотрите `git diff` перед каждым коммитом.
- Не давайте ассистенту секреты: пароли, ключи и токены не должны попадать в запросы и в файлы проекта.
- Результат — ваш код: вы его проверяете, вы за него отвечаете.

Хорошее упражнение для начала — попросить ассистента написать недостающие тесты к существующему коду: результат легко проверить, и он сразу полезен.
