Каждый запрос в Claude Code отправляет модели весь текущий разговор: ваши сообщения, прочитанные файлы, выводы команд. Чем длиннее сеанс, тем дороже каждый следующий вопрос — даже короткий. Поэтому экономия почти всегда сводится к одному: держать контекст небольшим.

## Как посмотреть расход {#see}

- `/usage` — расход текущего сеанса и, на командных планах, разбивка по навыкам, помощникам и подключениям.
- `/context` — что именно занимает контекст.
- `/insights` — отчёт о том, как вы работаете и где теряете время.

## Десять привычек {#habits}

<ol class="rai-principles">
<li><b><code>/clear</code> между задачами</b><span>Старый контекст оплачивается в каждом следующем сообщении. Перед очисткой — <code>/rename</code>, чтобы вернуться позже.</span></li>
<li><b>Модель по задаче</b><span>Sonnet — для большинства задач, Opus — для сложной архитектуры и рассуждений. Переключение — <code>/model</code>.</span></li>
<li><b>Конкретный запрос</b><span>«Добавь проверку ввода в функцию входа в auth.ts» вместо «улучши код» — меньше лишних чтений.</span></li>
<li><b>План для сложного</b><span>Режим плана предотвращает дорогие переделки, когда направление было неверным.</span></li>
<li><b>Остановить рано</b><span><code>Esc</code> сразу, как только Claude пошёл не туда; <code>/rewind</code> — откат.</span></li>
<li><b>Короткий CLAUDE.md</b><span>До 200 строк; специальные процедуры — в навыки, они загружаются только при надобности.</span></li>
<li><b>Шумное — помощникам</b><span>Логи, тесты, документацию пусть читает помощник; в разговор вернётся только вывод.</span></li>
<li><b>Командная строка вместо MCP</b><span><code>gh</code>, <code>aws</code>, <code>gcloud</code> экономнее по контексту; ненужные подключения — отключить в <code>/mcp</code>.</span></li>
<li><b>Меньше размышлений для простого</b><span>Для простых задач можно снизить уровень усилия командой <code>/effort</code>.</span></li>
<li><b>Проверка в запросе</b><span>Тесты и ожидаемый результат сразу — Claude ловит ошибки сам, без лишних кругов.</span></li>
</ol>

## Почему растёт расход в долгом сеансе {#why}

Длинный контекст, перерывы (после паузы кэш истекает и история обрабатывается заново), задачи по расписанию и помощники — все они отправляют свои запросы. `/compact` тоже стоит запроса, а `/clear` — бесплатен.
