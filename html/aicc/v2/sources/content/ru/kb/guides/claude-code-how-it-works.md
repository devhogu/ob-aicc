Claude Code — не чат с подсказками по коду, а помощник, который сам действует: читает файлы, правит их, запускает команды. Хотя он создан для разработки, ему можно поручить почти всё, что делается из командной строки: документацию, сборки, поиск по файлам.

<ol class="rai-flow">
<li><b>Собрать контекст</b><span>найти и прочитать нужные файлы, понять задачу</span></li>
<li><b>Действовать</b><span>править код, запускать команды и тесты</span></li>
<li><b>Проверить</b><span>посмотреть результат и, если нужно, повторить</span></li>
</ol>

Цикл подстраивается под задачу: на вопрос хватит чтения, на исправление ошибки — нескольких кругов. Вы — часть цикла: можно прервать и направить в любой момент.

## Инструменты {#tools}

Файлы (читать, править, создавать), поиск (по именам и содержимому), выполнение (команды, тесты, git), веб (документация, поиск), а также подсказки редактора кода при установленных плагинах. Расширения — навыки, подключения MCP, хуки, помощники — добавляются поверх.

## Что видит Claude {#access}

Ваш проект, ваш терминал (всё, что можете запустить вы), состояние git, файл `CLAUDE.md` и автоматическую память, а также настроенные вами расширения.

## Сеансы и контекст {#sessions}

- Каждый сеанс начинается с чистого контекста; постоянные правила кладите в `CLAUDE.md`.
- `claude --continue` продолжает последний сеанс, `claude --resume` — выбрать из списка.
- Когда контекст заполняется, Claude сжимает историю — ранние подробные указания могут потеряться. `/context` показывает, что занимает место.

## Безопасность {#safety}

<div class="rai-cards rai-cards--3">
<article><h3>Откат</h3><p>Перед каждой правкой Claude сохраняет снимок файла. <code>Esc</code> дважды — вернуться назад. Внешние действия — базы, API, развёртывание — откатить так нельзя.</p></article>
<article><h3>Режимы разрешений</h3><p>Переключаются Shift+Tab: <b>Auto</b> — рискованное блокирует проверяющая модель; <b>Manual</b> — спрашивает перед правками и командами; <b>Accept edits</b> — правит без вопросов; <b>Plan</b> — только изучает и предлагает план.</p></article>
<article><h3>Делегируйте, не диктуйте</h3><p>Дайте контекст и цель, как способному коллеге, — какие файлы читать, Claude разберётся сам.</p></article>
</div>
