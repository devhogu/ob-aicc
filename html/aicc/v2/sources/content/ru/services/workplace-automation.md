[[workspace-automation|Автоматизация рабочего места]] берёт на себя повседневную работу подразделения: маршрутизацию запросов, чтение и заполнение форм, обработку отчётов, сведение входящих данных и подготовку документов по шаблонам. Помощник готовит материал, а сотрудник проверяет его и решает, что с ним делать.

## Что входит

Автоматизация живёт в тех инструментах, которыми подразделение уже пользуется:

- классификация и маршрутизация запросов и сообщений;
- извлечение данных из форм и заполнение форм;
- обработка и сводка отчётов;
- сведение входящих данных из нескольких источников;
- типовые документы по шаблонам из собранных сведений;
- помощь в работе с обращениями в узких рамках.

У каждой автоматизации есть сотрудник, который проверяет результат, прежде чем тот пойдёт дальше; насколько глубоко проверять, зависит от [[risk-tier|уровня риска]]. Это [[human-in-the-loop]]. Автоматизация, которая сама действовала бы в системах Банка или с деньгами без проверки, сюда не относится.

## С чем приходят

- Классификация и маршрутизация запросов, жалоб и сообщений.
- Извлечение данных из форм и документов, заполнение форм.
- Обработка и сводка регулярных отчётов; классификация расхождений при сверке.
- Сведение входящих данных из нескольких источников в один рабочий файл.
- Документы по шаблонам из собранных сведений, которые проверяет сотрудник.
- Помощь с обращениями: найти связанные обращения, предложить допустимый следующий шаг, подготовить объяснение со ссылками на источники.

## Что вы получите

Работающие автоматизации. У каждой есть короткое описание, уровень риска, шаг проверки результата и ответственный в подразделении; есть короткая инструкция для пользователей и запись в каталоге автоматизаций, чтобы другое подразделение могло взять её себе. Сотрудники освобождают время для более ценной работы, а результаты становятся ровнее.

## Как идёт работа

Это обычно [[run-rate]]: за несколько дней мы вместе понимаем размер задачи, за одну [[iteration|итерацию]] делаем автоматизацию со специалистом подразделения, проверяем её и передаём подразделению. Набор автоматизаций для целого процесса становится [[initiative|инициативой]] и начинается с изучения.

## Что остаётся для следующих

Каталог автоматизаций: каждая автоматизация становится [[reusable-package|пакетом]] с подключениями, запросами к модели и правилами, шагом проверки результата и указаниями по развёртыванию.

## Форма работы

[[run-rate|Текущая работа]] для отдельных автоматизаций; [[initiative|инициатива]] для процесса. Использовать автоматизацию на данных нужного класса решает [[business-owner|бизнес-владелец]], а результат проверяет ответственный в подразделении.
