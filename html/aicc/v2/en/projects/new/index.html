Create a card

Create a card, and your project will appear in every view of this section.

  1. Copy the template below into a file named cards/IDENTIFIER.yaml.
  2. Fill in the required fields: identifier, title, summary, profile, state, people’s positions, problem and intended outcome, and current status.
  3. For an idea, set the state to Воронка (Funnel). You can add the rest later.
  4. Update the card as the work goes on: the next build shows the changes in every view.

A schema checks the card: the build stops and tells you what to fix. The schema is cards/schema.json.

Template

# Project card template (English edition). Copy the file, name it after the card ID (INI-020.yaml) and fill it in.
# Required: id, title, summary, profile, stage, people, outcome, live. Put any text that contains a colon in double quotes.
# The site is written in Russian first: Russian fields hold the source text, and each English text sits beside its Russian field with _en. This template shows the English fields; take the Russian ones from the Russian template.
# Fixed values (class_of_service, stage, state, status) are written in Russian exactly as listed; their English names are shown in the comments.
id: INI-000
title: Project name in Russian
title_en: Project name
summary: One or two sentences in Russian.
summary_en: One or two sentences on what we are doing.
profile: initiative            # initiative | run-rate | recurring-check | enablement
class_of_service: инициатива   # инициатива = initiative | текущая работа = run-rate work | срочная работа = urgent work
stage: Воронка                 # Воронка = Funnel | Проработка = Shaping | Готово к старту = Ready | В работе = Doing | Завершено = Done | Отложено = Deferred | Закрыто = Closed
function_en: ""                # the function that needs the result
area_en: ""                    # the service, for example "Knowledge services"
people:
  business_owner: {position_en: "who in the function owns the result", holder: ""}
  product_manager: {position_en: "who owns what we build", holder: ""}
  project_manager: {position_en: "who runs the project", holder: ""}
outcome:
  problem_en: The problem or need.
  intended_outcome_en: The result we want.
  measure_en: How we measure it.
  baseline_en: How it is now.
  target_en: How we want it to be.
constraints:
  appetite_en: How much effort we are ready to put in.
  review_point_en: When we check whether to continue.
  exit_criterion_en: When we consider the step done.
  stop_threshold_en: When we stop.
checklist:
  - {item_en: "Practice checklist: item", state: "не начато"}   # не начато = not started | сделано = done | не нужно = not needed
live:
  status: не задан             # зелёный = green | жёлтый = yellow | красный = red | не задан = not set
  next_step_en: ""
  risks_en: []
  dependencies_en: []
work:
  - {id: CAP-000, type: capability, title_en: "Capability", state: Бэклог}   # Бэклог = Backlog
  - {id: FEAT-000, type: feature, parent: CAP-000, title_en: "Feature", state: Бэклог, jira: ""}
decisions: []                  # - {what_en: "what was decided", who: "who", when: "when"}
closure: {result_en: "", lessons_en: ""}
links: {jira: "", confluence: ""}
