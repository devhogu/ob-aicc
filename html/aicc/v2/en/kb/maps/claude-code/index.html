Learning map: Claude Code

Go from your first session in a repository to long unattended runs of Claude Code, checking the result and following the rules of a regulated organization.

RoadmapSpecialization · for developersStart with step 1 →

Who it's for: for developersSteps: 13 · about 5 h
0 of 13
Level 1

Beginner

  1. 1
    Claude Code: your first session in a repositoryguide · 8 min

    Start Claude Code, create a CLAUDE.md, and give it its first task.

    Try this: In your own branch, run /init, add the test command to CLAUDE.md, ask for a change that comes with a test, and check the git diff.

  2. 2
    How Claude Code worksguide · 6 min

    Understand the agentic loop, tools, sessions, and permission modes.

    Try this: Switch modes with Shift+Tab and look at /context after your first question.

  3. 3
    Claude Code: everyday recipesguide · 7 min

    Use the recipes: understand the code, fix a bug, and write tests.

    Try this: Ask Claude to write the missing tests for one module.

Checkpoint. You work with Claude Code in your repository on everyday tasks.

Level 2

Practitioner

  1. 4
    Claude Code: practices that workguide · 8 min

    Give Claude a way to check its work, work from a plan, and keep the context clean.

    Try this: Take one task through plan mode, then run the tests and read their output.

  2. 5
    Set up Claude Code for your project: CLAUDE.md, permissions, skills, hooksguide · 8 min

    Set up CLAUDE.md and allow/deny permissions, and choose between a skill, a subagent, a hook, and an MCP server.

    Try this: Block reading .env with a deny rule and check that the read is refused.

  3. 6
    Claude Code: how to save context and budgetguide · 5 min

    Use the ten habits that save context and budget.

    Try this: Compare /context and /usage at the start and end of a task.

Checkpoint. Your sessions are effective, your project is set up, and costs are under control.

Level 3

Advanced

  1. 7
    Subagents in Claude Codeguide · 8 min

    Design subagents and understand when you need them.

    Try this: Create a read-only security-reviewer subagent and call it with @.

  2. 8
    Hooks in Claude Code: what must always happenguide · 6 min

    Turn required actions into hooks.

    Try this: Write a PreToolUse hook that blocks edits to .env, and check that the block works.

  3. 9
    MCP connections: Claude Code and your toolsguide · 6 min

    Connect approved systems with minimal permissions and without keys in the repository.

    Try this: Run claude mcp list and turn off anything you don’t need in /mcp.

Checkpoint. You extend Claude Code with subagents, hooks, and MCP servers.

Level 4

Expert

  1. 10
    Claude Code in action: long sessions, automation, and review — the complete guideguide · 40 min

    Set a goal that can be verified, choose the mode and automation, and review unattended work by its diff.

    Try this: Set a /goal of passing tests and check the result by the diff, not the summary.

  2. 11
    Safety in a regulated organizationpart of a guide · 10 min

    Apply the Claude Code settings that matter for sensitive repositories.

  3. 12
    Claude Code documentation ↗documentation, EN · 120 min

    Look up any feature in the primary source.

  4. 13
    Course: Claude Code in Action ↗course, EN · 60 min

    Complete the Anthropic course, with a certificate.

Checkpoint. You run long unattended work and check the result with confidence.
