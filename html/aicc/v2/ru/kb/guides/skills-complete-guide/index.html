Навыки Claude: полное руководство

← Все руководстваClaudeполное руководство30 мин

Руководство для всех, кто устал вставлять в каждый разговор одну и ту же инструкцию. После него вы сможете написать свой навык, включить его в Claude, проверить на настоящих задачах и безопасно поделиться им с коллегами.

Навык (skill) — способ один раз объяснить Claude, как делать определённую работу, и больше не повторять это в каждом разговоре. Это самый простой путь от «я каждый раз вставляю одну и ту же инструкцию» к автоматизации своей работы.

Руководство в девяти частях, каждая открывается своей вкладкой. Части 1–4 нужны всем, кто работает в Claude; часть 5 — тем, кто пользуется Cowork или Claude Code; части 6–9 — тем, кто пишет навыки сам.

1. Что такое навык

Навык — это папка с инструкциями, а при необходимости ещё с шаблонами, примерами и скриптами (небольшими программами). Главный файл называется SKILL.md. Claude применяет навык сам, когда видит, что тот подходит к задаче.

Документация Anthropic выделяет два вида навыков:

Справочный навык

Знания, которые нужно применять: стандарты оформления, фирменный стиль, глоссарий, правила расчёта. Claude подключает его сам, когда тема всплывает в работе.

Навык-процедура

Пошаговые действия: «подготовь ежемесячный отчёт», «проверь договор по списку». Такой навык чаще вызывают вручную — командой /имя.

Когда пора делать навык

  • Вы в третий раз вставляете в разговор одну и ту же инструкцию, чек-лист или порядок действий.
  • Одну и ту же процедуру выполняют несколько коллег — и делают по-разному.
  • Есть стандарт оформления, о котором Claude постоянно приходится напоминать.

Пока навык не нужен, он почти ничего не стоит. В разговоре всегда видно только его короткое описание — около сотни токенов (token) (токен — слово или часть слова), а полный текст загружается, лишь когда Claude решает навык применить.

2. Навык и другие возможности

У Claude несколько способов «запомнить» что-то надолго. Вот как документация Anthropic разводит их между собой.

Возможность Что даёт Когда загружается Чем отличается от навыка
Проект Постоянные документы и инструкции для одной темы Всегда, в чатах этого проекта Проект — про тему и её материалы; навык — про способ работы и работает в любом чате
Пользовательские инструкции Ваши общие предпочтения Во всех разговорах Инструкции — для всего; навык — для конкретной задачи и только когда нужен
Подключения (коннекторы, MCP) Доступ к внешним системам: почта, трекер, хранилище Когда Claude обращается к системе Подключение даёт доступ к инструменту; навык учит правильно им пользоваться
CLAUDE.md (Claude Code) Правила проекта для разработчиков В каждой сессии CLAUDE.md — для правил «всегда»; навык — для того, что нужно иногда
Помощники (subagents) Отдельный исполнитель со своим контекстом По поручению Навык работает в вашем разговоре; помощник — в отдельном
Хуки (Claude Code) Команда, которая выполняется автоматически при каждом событии При событии Навык — это просьба, которую Claude толкует сам; хук — гарантия без исключений
Плагины Упаковка навыков, хуков, помощников и подключений При установке Плагин — это «коробка», в которой навыки распространяют

Простое правило: знания для темы — в проект, способ работы — в навык, обязательное правило — в хук, доступ к системе — через подключение.

В этой части — из чего состоит навык и как написать его главный файл SKILL.md, чтобы Claude применял навык в нужный момент. Она пригодится, даже если файл за вас составит Claude: описание всё равно стоит проверить самому.

Навык — это папка. Обязателен в ней только SKILL.md; для первого навыка его достаточно. Так выглядит папка навыка посложнее:

monthly-report/
├── SKILL.md        обязательный: описание и инструкции
├── template.xlsx   шаблон, который Claude заполнит
├── examples.md     образцы хорошего результата
└── scripts/
    └── check.py    проверка, которую Claude запустит

SKILL.md — обычный текстовый файл. В нём две части: короткая «шапка» между строками --- с названием и описанием, а под ней — сами инструкции.

---
name: monthly-report
description: Готовит ежемесячный отчёт по продажам из выгрузки в Excel
  по стандарту финансовой службы. Используй, когда просят месячный отчёт,
  сводку продаж за месяц или отчёт для руководства по продажам.
---

# Ежемесячный отчёт по продажам

1. Возьми выгрузку, которую приложил пользователь.
2. Заполни шаблон template.xlsx: лист «Данные», затем «Сводка».
3. Все итоги — формулами, а не готовыми числами.
4. Сравни с прошлым месяцем; отклонения больше 10% отметь и объясни.
5. В конце перечисли, что нужно проверить автору.

Правила для шапки

  • name — короткое имя латиницей: строчные буквы, цифры и дефисы, до 64 символов, без слов «claude» и «anthropic». Например, service-memo. Имя папки должно совпадать с ним.
  • description — что делает навык и когда его применять. Именно по описанию Claude решает, подходит ли навык к просьбе. Документация платформы допускает до 1024 символов, но в приложении Claude ограничение может быть строже — для надёжности держите описание коротким и точным.

Сравните два описания:

  • Плохо: «Помогает с документами». Непонятно, что именно делает навык и когда его брать.
  • Хорошо: «Оформляет служебную записку по внутреннему стандарту: адресат, тема, суть, предложение, срок. Используй, когда просят служебную записку, записку руководителю или внутреннее обращение». Есть и результат, и слова, которыми люди просят.

Постепенное раскрытие

Это главный принцип навыков: Claude читает ровно столько, сколько нужно.

  1. Всегданазвание и описание — около 100 токенов на навык (токен — слово или часть слова)
  2. Когда навык подходиттекст SKILL.md — обычно меньше 5 тысяч токенов
  3. Когда нужношаблоны, справочники, скрипты; от скрипта в разговор попадает только результат

Поэтому в навык можно положить объёмный справочник: он не мешает, пока не понадобится. Сам SKILL.md держите короче 500 строк, а подробности выносите в отдельные файлы с понятными ссылками на них.

В этой части — как включить навыки в рабочем аккаунте, загрузить свой навык или создать его прямо в разговоре и как понять, что он сработал. Интерфейс Claude на английском: названия меню и кнопок даны в кавычках так, как они написаны на экране, а перевод — в скобках.

Включить

Навыкам нужна включённая возможность «Code execution and file creation (Выполнение кода и создание файлов)».

  • Рабочий аккаунт (Team, Enterprise): выполнение кода и навыки администратор включает в параметрах организации (Organization settings). В Team это включено по умолчанию. Если навыков у вас нет — обратитесь к администратору.
  • Личные планы (Free, Pro, Max): выполнение кода включают в «Settings → Capabilities (Параметры → Возможности)». Но рабочие задачи решайте только в одобренном рабочем аккаунте.
  • Отдельные навыки включают и выключают в «Customize → Skills (Настройка → Навыки)».

Готовые навыки для документов

Anthropic даёт готовые навыки для Word, Excel, PowerPoint и PDF. Вызывать их не нужно: если создание файлов включено, Claude сам применит нужный, когда вы попросите, например, «сделай презентацию о результатах квартала» или «собери таблицу с формулами».

Навык для Excel следует правилам финансового моделирования: итоги — формулами, а не готовыми числами; вводимые данные — синим, формулы — чёрным, ссылки на другие листы — зелёным; отрицательные числа — в скобках; допущения — в отдельных ячейках.

Добавить свой навык

  1. Сложите папку навыка в ZIP-архив так, чтобы папка была в корне архива. В Windows для этого достаточно щёлкнуть по папке правой кнопкой и выбрать «Отправить → Сжатая ZIP-папка».
  2. «Customize → Skills (Настройка → Навыки)» → «+» → «Create skill (Создать навык)» → «Upload a skill (Загрузить навык)».
  3. Включите навык и попробуйте на задаче.

Частые ошибки загрузки: архив слишком большой, имя папки не совпадает с полем name, нет файла SKILL.md, недопустимые символы в названии или описании.

Создать навык в разговоре

Писать файл самому не обязательно. Скажите Claude «давай сделаем навык для…» и опишите процедуру. Claude с помощью встроенного навыка-конструктора задаст вопросы, напишет SKILL.md и упакует его — останется загрузить. Для первого навыка это самый простой путь.

Как понять, что навык сработал

В ходе работы Claude показывает строку вроде «Reading [название навыка]» или «Using [название]». Нет строки — навык не подключился: скорее всего, его описание не совпало с вашей просьбой.

Навыки, включённые в Claude, работают и в надстройках Claude для Excel, PowerPoint, Word и Outlook — там их можно вызвать через /.

Попробуйте сейчас: навык «служебная записка».

  1. В новом разговоре напишите: «Давай сделаем навык для служебной записки. Возьми за основу этот образец» — и вставьте образец из части «Образцы». Поправьте структуру под стандарт своего подразделения.
  2. Загрузите навык, который подготовит Claude, и включите его.
  3. В другом новом разговоре попросите: «Напиши служебную записку начальнику отдела о переносе срока сдачи отчёта». Проверьте, что появилась строка с названием навыка и записка идёт по вашей структуре.

5. Навыки в Cowork и Claude Code

Эта часть — для тех, кто работает в Cowork или в Claude Code (инструменте для разработчиков). Остальные могут её пропустить.

Cowork

Cowork использует навыки вашего аккаунта Claude. Управление — через «Customize (Настройка)» на боковой панели настольного приложения; навыки организации устанавливаются из каталога: «Customize → + → Skills → Install (Настройка → + → Навыки → Установить)». В Claude для Mac на планах Pro, Max и Team есть запись навыка: вы показываете процедуру на экране и комментируете голосом, а Claude предлагает навык по записи.

Claude Code

Где лежит Для кого
~/.claude/skills/имя/SKILL.md лично для вас, во всех проектах
.claude/skills/имя/SKILL.md для всего проекта — храните в git вместе с кодом
в плагине для всех, кто установил плагин; вызов /плагин:навык
из аккаунта Claude синхронизируются, если вы вошли через /login
  • /имя в начале сообщения — вызвать навык; /skills — посмотреть все загруженные.
  • В Claude Code в шапке есть дополнительные поля: disable-model-invocation: true — навык вызывается только вручную (так делают для процедур с последствиями, например публикации); allowed-tools — какие действия разрешены без вопроса; $ARGUMENTS в тексте — подставить то, что написали после команды.
  • Эти дополнительные поля работают только в Claude Code. Навык для приложения Claude должен содержать в шапке только стандартные поля, иначе загрузка завершится ошибкой.

В этой части — девять правил из руководства Anthropic по написанию навыков. Применяйте их, когда пишете или правите SKILL.md: по ним видно, почему навык срабатывает не вовремя или даёт нестабильный результат. Напомним: навык — это папка с главным файлом SKILL.md, где в «шапке» есть название и описание, а ниже — инструкции.

  1. КороткоClaude и так умён, а каждое слово навыка занимает место в разговоре. Для каждого абзаца спросите: «Стоит ли он места, которое занимает?» Пишите, что делать, а не рассказывайте, почему.
  2. Описание — главноеЧто делает и когда применять, теми словами, которыми люди просят. Пишите в третьем лице: «Готовит отчёт…», а не «Я помогу…». Claude чаще не применяет навык там, где мог бы, чем применяет лишний раз, поэтому описание может быть чуть настойчивым.
  3. Одна цельОдин навык — одна процедура. «Сводка протокола» и «служебная записка» — два навыка, а не один «всё про документы».
  4. Нужная степень свободыГде есть варианты — общие указания. Где ошибка дорога — точные шаги или готовый скрипт: «выполни ровно это, ничего не меняй».
  5. Чек-лист и проверкаДайте список шагов, который Claude отмечает по ходу, и петлю «проверь → исправь → проверь снова».
  6. Образец результатаШаблон или пример готовой работы — надёжнее любого описания формата.
  7. Один вариант по умолчаниюНе пять альтернатив, а одна рекомендуемая плюс запасная на особый случай.
  8. Без дат и «пока что»Не пишите сведений, которые устареют; устаревшие правила выносите в отдельный раздел.
  9. Единые терминыОдно понятие — одно слово по всему навыку: если «заёмщик», то везде «заёмщик», а не то «клиент», то «должник».

Справочники отдельно

Длинные материалы — в отдельные файлы, а в SKILL.md — короткая ссылка на них: «если нужно заполнить форму — прочитай forms.md». Так, список требований к договору удобно держать в отдельном checklist.md. Ссылки держите на один уровень вглубь, иначе Claude может прочитать файл не целиком. Файлу длиннее сотни строк нужно оглавление в начале.

Попробуйте сейчас. Откройте свой навык — например, «служебную записку» — и пройдите по девяти правилам. Чаще всего улучшать приходится описание (правило 2) и образец результата (правило 6).

В этой части — как убедиться, что навык действительно помогает: проверить его на трёх настоящих задачах с навыком и без него и улучшать по результатам. Anthropic советует начинать именно с проверки, а не с длинной инструкции.

  1. Три задачисоберите три настоящих примера, где навык нужен
  2. Без навыкапосмотрите, как Claude справляется сам, — это точка отсчёта
  3. Минимальный навыктолько то, чего не хватило
  4. Улучшатьпо результатам, после каждого изменения — снова три задачи

Например, для навыка «служебная записка» возьмите три записки, которые вы написали за последний месяц, уберите из них то, что нельзя передавать, и попросите Claude подготовить их заново — сначала с выключенным навыком («Customize → Skills (Настройка → Навыки)»), затем с включённым. По каждой задаче запишите, что пришлось исправлять. Если с навыком правок не меньше, навык пока не помогает.

  • Свежий взгляд. Один разговор пишет навык, другой — новый, без истории — проверяет его на реальных задачах.
  • Не срабатывает? Добавьте в описание слова, которыми люди на самом деле просят; проверьте, что навык включён.
  • Срабатывает лишний раз? Сузьте описание или сделайте навык вызываемым только вручную.
  • Правило иногда нарушается? Навык — это просьба, а не гарантия. Обязательное правило выносят из навыка: в Claude Code — в хук (команду, которая выполняется автоматически каждый раз) или в проверку-скрипт; в остальных случаях его соблюдение проверяет человек.
  • Навыки не могут явно ссылаться друг на друга, но Claude сам сочетает несколько подходящих.

В этой части — как проверить навык, прежде чем его включить, и как поделиться проверенным навыком с коллегами.

Навык — это, по сути, программа: в нём могут быть скрипты и инструкции, которые Claude выполнит. Поэтому к нему относятся так же, как к установке программного обеспечения.

Доверенные источники

Только навыки, созданные вами, вашей организацией или Anthropic. Даже навык коллеги — проверить перед включением.

Проверка перед включением

Прочитать все файлы; скрипты запускать только в изолированной среде; искать сетевые вызовы, пароли в тексте, инструкции «отправь данные туда-то». Не можете оценить скрипт — не включайте навык, передайте его на проверку.

Четыре глаза

Автор навыка не проверяет его сам. Для каждого навыка — несколько контрольных задач.

Главные риски — внедрение чужих инструкций (prompt injection) (текст в файле навыка или документе, который Claude выполнит как команду) и утечка данных (data leakage).

В организации (Team и Enterprise)

  • Владелец организации в Claude может предоставить навык всем в параметрах организации (Organization settings). В Enterprise навыки можно ограничить группами.
  • Отдельным переключателем владелец может запретить сотрудникам создавать свои навыки.
  • Публикация навыка для всей организации идёт через обязательную проверку: проверяющий видит версию, результаты сканирования, все файлы и изменения; одобрить собственную заявку нельзя.
  • В Enterprise есть автоматическое сканирование навыков на безопасность, но «пройдено» — не гарантия: проверка людьми остаётся.
  • Ведите реестр навыков: назначение, владелец, версия, статус проверки. Исходники навыков храните в системе контроля версий (git).

Как поделиться своим навыком.

  1. Проверьте его на трёх задачах — как в части «Проверка и улучшение».
  2. Попросите коллегу прочитать все файлы и прогнать свои контрольные задачи.
  3. Отправьте навык на публикацию в организации через проверяющего. Если навыки в вашей организации ещё не распространяются централизованно — расскажите нам о своём навыке: полезные многим мы проверим и добавим в общую библиотеку навыков (skill library).

Служебная записка

---
name: service-memo
description: Оформляет служебную записку по внутреннему стандарту: адресат,
  тема, суть, предложение, срок. Используй, когда просят служебную записку,
  записку руководителю или внутреннее обращение.
---

# Служебная записка

Структура — строго в таком порядке:
1. Кому (должность, подразделение) и от кого.
2. Тема — одна строка, начинается с существительного.
3. Суть — 3–5 предложений: что произошло или что нужно.
4. Предложение — что просим сделать, нумерованным списком.
5. Срок и контакт для вопросов.

Тон деловой, без канцелярских оборотов вроде «в целях обеспечения».
Объём — не больше одной страницы.
В конце перечисли, каких сведений не хватило, если пользователь их не дал.

Проверка договора по списку

Навык-процедура: файл SKILL.md с шагами «прочитай договор → пройди по checklist.md → по каждому пункту: соответствует / не соответствует / нет в договоре, с цитатой → итог: таблица и три главных риска». Сам список требований лежит отдельным файлом — его легко обновлять, не трогая процедуру. Решение о договоре принимает юрист: навык готовит разбор, а не заключение.

Официальные образцы Anthropic

В открытом репозитории навыков Anthropic стоит посмотреть: internal-comms — внутренние сообщения по образцам разных типов; brand-guidelines — чисто справочный навык с цветами и шрифтами; pdf — как раскладывать подробности по отдельным файлам; skill-creator — навык, который помогает создавать навыки.

Короткая версия этой темы — Навыки: научить Claude вашей процедуре; навыки в разработке — Настроить Claude Code под проект.

По материалам: Agent Skills — документация платформы, Claude Code и Справочного центра — официальная документация Anthropic на русском. Здесь — короткая выжимка с нашими примерами.
