SPOM as a portfolio control plane

The control plane does not run the services itself. It exposes the front door, stores the portfolio state, applies policies, schedules investment, and runs controller loops across Managed Services.

Visual metaphor

SPOM behaves like a control plane. Managed Services behave like managed resources. Actual platform services remain the runtime capability.
