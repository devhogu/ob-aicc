Service Portfolio and Operating Model as a control plane

These pages are pure HTML prototypes. They test how SPOM can be understood as a portfolio-level control plane that admits, governs, prioritizes, and steers Managed Shared Services.

Prototype intent

Find the visual language first. Once the model feels right, the same boxes can become graph-backed nodes.
