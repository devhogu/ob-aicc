# Flow redesign: research and intent

This folder keeps the evidence for the redesign of the end-to-end process of the Competence Center: the portfolio end to end, the program execution, and the two floors, functional and governance. The intent, the constraints, the target model, the refactor phases and the open decisions are recorded in the draft change [C-FLOW-REDESIGN](../../../.grace/changes/active/C-FLOW-REDESIGN/spec.xml) and its [design context](../../../.grace/changes/active/C-FLOW-REDESIGN/design-context.xml). Nothing here changes a rule: the corpus is amended only through the phases of that change, each with its Decision Record.

| File | Holds |
| --- | --- |
| [00-brief.md](00-brief.md) | The brief given to the six research agents |
| [01-safe-portfolio-and-program.md](01-safe-portfolio-and-program.md) | SAFe: Lean Portfolio Management, the Portfolio Kanban, guardrails, WSJF, the Program level |
| [02-other-agile-portfolio-methods.md](02-other-agile-portfolio-methods.md) | Kanban Method, Disciplined Agile, Scrum@Scale, Beyond Budgeting, Lean Startup, product operating model, OKRs |

| [05-controls-in-agile-for-banks-and-ai.md](05-controls-in-agile-for-banks-and-ai.md) | Risk-tiered controls in the flow, the three lines model, model risk, ISO/IEC 42001, NIST AI RMF |
