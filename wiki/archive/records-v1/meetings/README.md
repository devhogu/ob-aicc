# Minutes of the Forums

This folder holds the agenda and minutes of the Forums that keep minutes, as the Governance Forums state. One subfolder for
each Forum, and one file for each meeting, named with the date.

| Replenishment | Meeting Agenda; Meeting Minutes | [replenishment/](replenishment/) |
| Delivery Review | Delivery Review Notes | [programs/main/reviews/](../programs/main/reviews/) |
| Design Review | Meeting Agenda; Meeting Minutes | [design-review/](design-review/) |
| Control Review | Meeting Agenda; Meeting Minutes | [control-review/](control-review/) |

The Stand-up and the Community of Practice keep no minutes, and this folder holds no subfolder for them.
